## 1. 인프런 (inflearn.com)

**한 줄 평**: 정보 밀도형 — 친근한 그린 톤, 깔끔한 카드 그리드.

**컬러**
- 메인 액센트: **그린** (#00C471 추정) — 로고·CTA·태그
- 배경: 화이트
- 텍스트: 진한 그레이 / 옅은 그레이 hierarchy

**타이포·레이아웃**
- 한글 폰트: Pretendard 추정 (Spoqa·Noto 가능)
- 헤더 미니멀: 로고 + 6개 메뉴 + 검색 + 우측 액션
- 검색바: 둥근 알약 모양, 강한 강조 (메인 시각 요소)
- 카드 그리드: 5컬럼 (데스크탑) → 모바일 1컬럼
- 카드 라운드: ~8px (작은 편)
- 강의 카드: 썸네일 16:9 + 강의명 2줄 + 강사 + 가격

**가져올 것**
- 검색바를 메인 시각 요소로 강조하는 패턴
- 카드 그리드의 5컬럼 정보 밀도 (단, Core Compass 1페이지 LP라 직접 적용은 X)
- 그린 액센트 같은 차분한 액센트 컬러 (코랄도 같은 카테고리)

## 2. 클래스101 (class101.net)

**한 줄 평**: 임팩트형 — 다크 배경, 컬러풀 카드, 강한 헤드라인 (Core Campus와 톤 정반대).

**컬러**
- 배경: **완전 블랙** (#000)
- 액센트: **오렌지** (#FF5722 추정) — 하단 sticky CTA "시작하기"
- 카드: 다양한 채도 — 핑크·블루·민트·옐로우
- 텍스트: 흰색

**타이포·레이아웃**
- 폰트: 두꺼운 한글 (Bold/ExtraBold 위주)
- 카드: 둥근 모서리 12~16px / 큰 썸네일 (포커스 강함)
- 카테고리 아이콘: 노란 박스 + 작은 그래픽 (예: 어도비·디지털 드로잉)
- 헤드라인: "30분 투자로 만드는 평생 디지털 연금 1천만원" → **우리가 피해야 할 카피 톤**
- 별점·후기 노출 명시적

**가져올 것 / 피할 것**
- ✓ 카드 그리드의 시각적 임팩트
- ✓ 카테고리 아이콘 통일된 디자인
- ✗ 다크 배경 (Core Campus는 베이지로 따뜻한 톤 유지)
- ✗ "1천만원" "평생" 같은 과장 카피
- ✗ 너무 많은 컬러 (시각 노이즈)

## 3. 패스트캠퍼스 (fastcampus.co.kr)

**한 줄 평**: 정통 학원 톤 — 화이트 베이스 + 핑크 액센트, 카테고리 균등 그리드.

**컬러**
- 배경: 화이트
- 액센트: **핑크-레드** (#E54336 추정) — 로고·"카테고리" 버튼
- 카테고리 아이콘: 각자 다른 컬러 박스 (보라·핑크·블루·코랄)

**타이포·레이아웃**
- 폰트: Pretendard 추정
- 헤더: 카테고리 드롭다운 + 9-10개 메뉴 한 줄 배치 (정보 많이 노출)
- 검색바: 둥근 풀 (인프런처럼)
- 카테고리 9개 그리드 (AI TECH, AI CREATIVE, AI/업무생산성, 개발/데이터, 디자인, 영상/3D, 금융/투자, 드로잉/일러스트, 비즈니스/기획)
- 상단 배너: 풀폭 배너 + 카운트다운 + "지금 확인하기" 강한 CTA

**가져올 것**
- 상단 한정 배너 (Hero 위 promo bar) — Core Compass "한정 100명·9,900원"에 활용 가능
- 카테고리 아이콘 컬러 다양성 — 6단계 분석 아이콘에 활용
- 화이트 + 단일 강한 액센트 색 조합

## 4. 토스 테크 (toss.tech)

**한 줄 평**: 절제의 정수 — 화이트 + 토스 블루, 큰 여백, 정보 위계 명확.

**컬러**
- 배경: **순백** (#FFFFFF)
- 액센트: **토스 블루** (#3182F6 추정) — 구독하기 CTA, 카테고리 라벨
- 텍스트: 진한 흑색 / 옅은 그레이

**타이포·레이아웃**
- 폰트: **Toss Product Sans** (Pretendard 기반 자사 폰트)
- 헤드라인: 매우 큰 사이즈 (44-48px), -0.03em 자간 (좁음)
- 본문: 16px, 회색 톤 (#666 추정)
- 카드 라운드: **24px** (큼)
- 그림자: 거의 없음
- 카테고리 배지: 옅은 파란 배경 + 진한 파란 텍스트 (`Engineering` 라벨)
- 우측 사이드바: "인기 있는 글" 1·2·3 번호 매김 — **숫자 매김이 안정감을 줌**

**가져올 것 (가장 많이)**
- ✓ 라운드 16~24px 큼
- ✓ 큰 헤드라인 (44px+) + 작은 본문 (16px) 강한 대비
- ✓ 카테고리 라벨 = 옅은 액센트 컬러 배경 + 진한 액센트 텍스트
- ✓ 숫자 매김 리스트 (인기 글 1,2,3) — Core Compass "받게 되는 것 01·02·03" 에 이미 적용됨
- ✓ 그림자 절제 (거의 없음)

## 5. 노션 KR (notion.com/ko)

**한 줄 평**: 자유로운 톤 — 다크 헤더 + 손그림 일러스트 + 컬러풀 카테고리.

**컬러**
- Hero 배경: **다크 네이비** (#1A1F2E 추정) + 일러스트
- 본문 영역: 화이트
- 액센트: **보라** (#5341FF 추정) — Notion 무료로 사용하기 CTA
- 캐릭터 일러스트: 옐로·블루·핑크 등 다채

**타이포·레이아웃**
- 폰트: Pretendard 풀
- 헤드라인: 매우 크고 굵게 ("잠들지 않는 AI 팀")
- 일러스트: 손그림 라인 + 둥근 캐릭터들
- CTA 2개 (Primary 보라 + Secondary 어두운 보더)
- 하단 클라이언트 로고 띠 (GS·카카오스타일·LG AI연구원·당근·sendbird·devsisters·AIR PREMIA·OpenAI·Figma)

**가져올 것**
- ✓ Hero에 일러스트 또는 SVG 아이콘 활용 (현재 v2는 텍스트만 — 빈 느낌)
- ✓ 클라이언트 로고 띠 (사회적 증거) — Core Compass는 출시 직후라 없으므로 "Core Campus 시리즈 데모" 식 라벨
- ✓ Primary + Secondary 두 개 CTA 패턴
- ✗ 다크 헤더 (Core Campus는 베이지 유지)
