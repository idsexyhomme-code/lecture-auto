## v2 → v3 변경 사항 (5가지)

### 1. 상단 Promo Bar (패스트캠퍼스 식)
```
🔥 한정 100명 · 출시 프로모션 9,900원 — 9,900원 결제하고 받기 →
```
풀폭 코랄 배경 + 화이트 텍스트. 페이지 스크롤시 사라짐 (sticky 아님).

### 2. Hero 시각 요소 (노션 식 + 회원 톤)
6개의 동그라미 — AI 에이전트 6명 시각화. 토스 옅은 배지 컬러 + 일러스트 톤.
배경에 살짝 그라데이션 (베이지 → 옅은 코랄 hint).

### 3. 카피 톤 강화 (회원님 친근 제주 톤)
- 현재 v2: "결제 후 개인 URL로 잠금 해제되는…"
- v3 추가: 부 헤드라인에 "딱, 한 장으로 정리해드릴게요" 식 친근한 한 줄
- Final CTA: "지금 결제, 30분 후 진단" → 유지하되 보조 카피 친근하게

### 4. 라운드·그림자 토스화
- 카드 라운드 16px → **20px**
- Pricing 카드 24px (가장 큼)
- 그림자 대부분 제거 (hover에만)

### 5. Pricing 임팩트 강화
- 가격 폰트 사이즈 50px → 64px
- "₩" 작게, 숫자 크게 (tabular-nums)
- 체크리스트 5개 → 6개 (추가: "한정 100명 출시가")
- 코랄 보더 → 코랄 그라데이션 보더 (절제)
