# yongyong.ai 분석 — 2026-05-17

> AI 사주·자미두수 진단 서비스. Core Compass와 유사 카테고리 (단발 진단형 상품).

## 사이트 구조 (관찰)

1. `/bot/{id}/intro` — 진입 페이지 (제품 소개 + D-카운트다운)
2. `/bot/{id}/form` — 진단 폼 (이름·성별 → 생년월일·시각)
3. (추정) 결제 페이지
4. (추정) 결과 페이지

## 핵심 UX 패턴 8가지

### 1. **D-카운트다운** — 긴급·한정 효과
> "당신의 인생이 바뀌는 날 D-27"

- 시간 흐름에 따라 자동 감소 (D-27 → D-21 → ...)
- 핑크 강조색 (#E91E63)
- 큰 폰트
- **심리 효과**: 시간 압박 — 미루지 말고 지금

→ **Core Compass v4 흡수**: "출시 프로모션 D-X" 또는 "한정 100명까지 남은 자리: XX/100" 같은 형태로

### 2. **사회적 증거 카운터** — 군중 심리
> "💟 18,488명이 확인했어요"

- 매 페이지 reload 시 살짝 증가 (실시간 카운터 또는 fake increment)
- 보라 하트 아이콘 + 작은 폰트
- CTA 버튼 바로 위 노출
- **심리 효과**: 다른 사람 다 했네 — 안전한 선택

→ **Core Compass v4 흡수**: "벌써 XX명이 진단 받았어요" — 출시 후 활성

### 3. **진행률 미리보기** — Endowed Progress Effect
> "리포트가 15% 완성됐어요!"

- 폼 시작 전부터 15% 표시
- 입력 진행 시 30%·45%·60%·... 100%로 증가
- 보라 강조색
- **심리 효과**: 이미 시작했으니 끝까지 → 이탈 감소

→ **Core Compass v4 흡수**: "AI 6명이 분석 준비 X% 완료" — 결제 폼에서 진행률 노출

### 4. **이름 호명 개인화**
> "감사해요, 테스트님."

- 다음 단계 화면부터 이름 호출
- 작은 인사 + 큰 메인 카피
- **심리 효과**: 1대1 대화 느낌 — 친밀감

→ **Core Compass v4 흡수**: 결제 폼 → 결과 페이지·이메일까지 일관된 이름 호명

### 5. **단계별 입력 (한 화면 한 질문)**
- 1단계: 이름 + 성별 (한 화면)
- 2단계: 생년월일 + 시각 (한 화면)
- 한 번에 1~2개 입력만
- **심리 효과**: 부담 적음 — 빠르게 진행

→ **Core Compass v4 흡수**: 결제 폼이 한 페이지에 다 있지만, 시각적으로 단계 분리 (1·2·3)

### 6. **점진적 약속 효과**
- 작은 약속 (이름) → 중간 약속 (생년월일) → 큰 약속 (결제)
- **심리 효과**: 일관성 욕구 — 시작했으니 끝까지

→ **Core Compass v4 흡수**: 진단 시작 전에 작은 사전 질문 1개 추가 ("어떤 영역에 가장 막혀 있나요?")

### 7. **모바일 우선 UX**
- 한 손 조작 가능
- 화면 폭 매우 좁게 (max-width 400px 정도)
- 하단 sticky CTA (큰 보라 버튼)
- **심리 효과**: 어디서나 빠르게

→ **Core Compass v3 이미 모바일 우선 ✓**

### 8. **빠른 진행 (각 단계 5초 이내)**
- 페이지 로드 빠름
- 입력 직관적
- 다음 단계 즉시 진행

→ **Core Compass v4 흡수**: 결제 폼 입력 항목 최소화 (이메일만 필수)

## 카피 톤

### yongyong 카피
- "정확도 200% 용한 AI사주" (title — 과장)
- "별자리로 보는 나의 인생 흐름" (강한 단정)
- "당신의 인생이 바뀌는 날" (운명 강조)
- "리포트가 X% 완성됐어요" (긴급)

### Core Compass 톤 (헌법 §4 — 그대로 유지)
- "AI 6명이 한 장으로 정리" (자기이해)
- "당신의 1인 사업 진단" (실행 기반)
- "딱, 한 장으로 정리해드릴게요" (친근)

**카피 흡수 안 함** — 운명·인생 단정 톤은 §4 ban. 우리는 자기이해·실행 톤 유지.
**UX 패턴은 흡수** — 카운트다운·증거·진행률 등 심리 트릭은 사업 도메인 무관하게 보편적.
