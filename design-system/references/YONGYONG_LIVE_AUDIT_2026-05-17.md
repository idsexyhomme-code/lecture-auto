```
메인 그리드 카드 클릭

  ↓
2. /form Step 1 — 성별 ("처음 보는 사람 같은데... 성별이 어떻게 되지?")
  ↓
3. /form Step 2 — 생일 ("오호라, 미래를 알고 싶다고?")
  ↓
4. /form Step 3 — 시간 ("길일에 태어났구나" ← 작은 ego boost)
  ↓
5. /form Step 4 — 연애 상태 ("그렇군,")
  ↓
6. /form Step 5 — 직업 ("하나 더 답해주겠어?")  *사업해요* 옵션 존재
  ↓
7. /form Step 6 — 이름 ("이제 마지막 단계야 이름을 알려줘")
  ↓
8. 이메일 수집 ("자미두수 리포트를 보내줄게 이메일을 알려줄래?")
  ↓
9. /result 페이지 — 무료 미리보기 (Chapter 1 명반 분석 + 진짜 사주 명반 표시)
   18분 카운트다운 시작 + 후기 5점 표시
  ↓
10. 결제 페이지 (3개 옵션: 28,900 / 51,900 / 72,900)
```

**핵심 트릭**:
- 6스텝 form = sunk cost 만들기 (이미 5분 투자했으니 결제로 회수)
- 이메일 = lead magnet (결제 안 해도 retargeting 가능)
- 결과 페이지 무료 미리보기 = 호기심 자극 → 18분 카운트다운으로 결정 압박

### 위협
- **yongyong이 이미 우리 도메인 침공 중** (베타 무료 카테고리에 "부업 사주·재테크 사주·번아웃 사주·인생 로드맵 사주" 4개가 우리 Core Compass와 직접 충돌)
- **신뢰·인지도·트래픽·결제 시스템·6스텝 funnel** 다 갖춤
- **인생 책임 패키지 72,900원**으로 ARPU 매우 높음

### 우리 강점 (차별화 가능)
- **충동가 9,900원** 진입가 — yongyong 최저 28,900원 대비 압도적 저렴 (호기심 결제 유도)
- **AI 6명 다중 검증** — yongyong 단일 명리 vs 우리 다중 데이터
- **90일 실행 로드맵** — yongyong "운명 예측"으로 끝 vs 우리 실행 액션 제공
- **1인 사업 정조준 페르소나** — yongyong은 broad B2C, 우리는 niche specialist

### 권고 — C 전략 + 추가 무기

기존 C 전략(7개 상품) 유지하되:

1. **충동가 9,900원 → 깊은 진단 19,900원 → 90일 코칭 49,000원** 3-tier 가격 구조 명확화 (yongyong의 28,900 → 51,900 → 72,900 미러링하되 더 저렴)

2. **번들 신설** — Core Compass + Niche + Roadmap 90 = **정가 78,900원 → 39,900원** (49% 할인) 같은 패키지

3. **18분 카운트다운** 결과 페이지 — 우리도 이미 v6에 D-7 있으니 결과 페이지 변형 가능

4. **"yongyong이 안 답하는 질문"** 차별화 카피

   - "운명 = 예측. 우리 = 실행."
