## 1. Core Campus ↔ Core Compass 브랜드 관계

- **상위**: Core Campus (실행형 강의 플랫폼)
- **서브**: Core Compass (AI 6명이 협업해서 만드는 *진단 PDF* 데모)
- **관계**: Compass 구매자는 *Campus의 능력을 9,900원에 체험*. PDF 자체가 *AI 에이전트 협업 시스템의 데모*.
- 메인 메뉴 노출 X — 캠페인 페이지로만.

---

## 2. 별도 랜딩으로 테스트하는 이유

- Campus의 *실행* 톤과 Compass의 *재미·진단* 톤이 다름 (메인 신뢰도 보호)
- 저가 유입 funnel의 *전환율 테스트*를 메인 KPI와 격리
- 운세 변수가 들어가 헌법 §4 위반 위험 — 별도 격리 후 *데모 프레임*으로만 운영

---

## 3. 랜딩 핵심 메시지

**헤드라인 후보 3개 (한 줄·25자 이내)**

- 후보 1: "AI 6명이 만드는 당신의 1인 사업 진단"
- 후보 2: "9,900원으로 받는 AI 에이전트 6명의 진단"
- 후보 3: "Claude가 분석한 내 사업 성향 PDF"

**서브헤드**: "결제 후 개인 URL로 즉시 잠금 해제. 본업 시간 30분이면 받아봅니다."

---

## 4. 타깃 고객

- 1인 사업가 / 프리랜서 / 크리에이터 / 강사·코치
- *시작 못 하고 있거나 방향 막힌 사람*
- ChatGPT·Claude는 써봤지만 *나에게 맞춘 진단*은 못 받은 사람
- 9,900원이면 *호기심으로 살 만한* 단가

---

## 5. 상품 가격 제안

- **정식가**: 19,900원
- **출시 프로모**: 9,900원 (한정 100명까지)
- **가격 책정 근거**: 9,900원은 충동 구매 임계값 아래다. Claude API 1회 생성 비용 약 $0.10(약 140원)이므로 마진 구조는 안정적이다. 동시에 "공짜는 아니다"는 심리적 가중치가 생겨 PDF 열람률·퍼널 진입률이 무료 배포보다 높다. 저가 funnel의 목적은 수익이 아니라 *유료 결제 경험자 확보*와 Campus 정식 강의로의 연결이다.
- ★ 가격 변경은 회원 ✅ 필수 (헌법 §6)

## 6. PDF 리포트 목차 (에이전트별 7섹션)

1. **§ 당신의 일하는 성향** — market_research_agent
2. **§ 잘 맞는 사업 형태 3가지** — curriculum_agent
3. **§ 90일 실행 로드맵** — production_planning_agent
4. **§ 첫 SNS·랜딩 카피 초안 (당신 사업용)** — landing_copy_agent
5. **§ 90일 KPI 트래킹 시작 가이드** — kpi_report_agent
6. **§ 당신의 캐릭터 코드** (메타포 — 사주 데이터 *변수 1개*. *예측 X·재미 O*)
7. **§ CEO 한 줄 정리 + 첫 액션 3개** — CEO 에이전트

총 PDF 분량: 약 8~12페이지. 양산 가능 (Claude API 1회 = 약 $0.10).

## 7. 신청 폼 입력 항목

**필수**

- 이메일 (개인 URL 발송 + 후속 퍼널)
- 현재 일·사업 한 줄
- 가장 큰 고민 한 줄
- 90일 안에 달성하고 싶은 결과 한 줄

**선택**

- 생년월일시 (캐릭터 코드 변수 — 미입력 시 기본 캐릭터 부여)
- SNS 1개 (참고용)

※ 헌법 §6 개인정보 수집 — *최소한*만. 주민번호·주소 X.

## 8. 결제 완료 후 안내 문구 + 개인 URL 흐름

**결제 직후 화면**

> "결제 완료. AI 6명이 당신의 데이터를 분석 중입니다. 약 30분 후 입력하신 이메일로 *개인 URL*을 보내드립니다."

**이메일 본문**

> "Core Compass 진단 결과가 준비됐습니다.
> *24시간 동안* 아래 URL에서 무제한 열람 가능합니다 (스크린샷·인쇄로 저장 권장).
> https://core-compass.kr/r/{token}
>
> Core Campus 무료 강의가 궁금하시면 → https://idsexyhomme-code.github.io/lecture-auto/"

**개인 URL 페이지**

- 결제 전 페이지와 *같은 디자인*. 단 *블러 X·잠금 아이콘 X·본문 노출 O*
- 상단에 "당신의 토큰: ABC123" + 만료 시각
- 하단에 *"Core Campus 무료 강의 받기"* CTA (퍼널 진입)

## 9. Core Campus 무료 강의로 연결하는 후속 퍼널

**3단 흐름**

- **D+0**: 결제 완료 이메일 + PDF 링크 + *무료 강의 1개* 링크
- **D+3**: 후속 이메일 — "PDF 중 §3 90일 실행 로드맵 잘 보고 계신가요? 다음 강의가 도움 될 것 같아 보내드립니다" + 무료 강의 2번째 링크
- **D+7**: 마지막 이메일 — *Core Campus 정식 강의 30% 할인 쿠폰* (저가 → 중가 funnel 진입)

★ 이메일 자동 발송 시스템 도입은 회원 ✅ 필수 (헌법 §6)

## 10. 사용하면 안 되는 과장 표현

**금지**

- "사주로 *수익 예측*" (예측 X — 진단 톤)
- "운이 좋아진다" (보장 X)
- "100% 정확한 분석"
- "당신의 미래를 알려드린다"
- "이걸 모르면 평생 실패" (공포 마케팅)
- 일반 §4 금기 (월 1,000만 원 자동 / 클릭 몇 번으로 자동화 / 누구나 쉽게 돈 버는)
- 일반 §8 금기 (워크플로우·솔루션·효율적·여러분 등)

**권장**

- "AI가 *분석*한 당신의 *일하는 성향*"
- "참고용 진단·재미로 보는 캐릭터"
- "실행 계획 *예시*"
- "당신의 데이터로 만든 *맞춤 PDF*"
