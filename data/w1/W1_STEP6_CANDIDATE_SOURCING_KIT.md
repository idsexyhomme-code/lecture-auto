## 2. 후보 평가표 템플릿

### 2.1 평가 항목 8개 (각 0~5점)

**평점 기준 공통 룰**

- 0점: 확인 불가 또는 완전히 부재
- 3점: 있지만 파일럿 #1 주제와 직접 연결되지 않음
- 5점: 명확히 확인, 파일럿 #1 주제와 직접 연결됨

---

**1. 관련 실무 경험·포트폴리오**

| 점수 | 기준 |
|---|---|
| 0 | 포트폴리오 없음. 설명만 있고 사례 없음 |
| 3 | AI·자동화 관련 작업 사례 있으나 강의 형태 아님 |
| 5 | ChatGPT·Notion·Make·Claude 중 1개 이상으로 실무 강의 또는 튜토리얼 제작 이력 명확히 있음 |

---

**2. 후기 수·외부 신뢰 자료**

| 점수 | 기준 |
|---|---|
| 0 | 후기 10개 미만 또는 없음 |
| 3 | 후기 10~19개. 내용 구체성 보통 |
| 5 | 후기 20개 이상. 내용 구체적 ("Notion으로 실제 견적 관리 바꿨다" 수준) |

---

**3. 평점·신뢰도**

| 점수 | 기준 |
|---|---|
| 0 | 평점 4.5 미만 (자동 탈락 후보) |
| 3 | 평점 4.7 이상 4.8 미만 |
| 5 | 평점 4.8 이상. 최근 3개월 후기에도 4.8 이상 유지 |

---

**4. 응답 속도·커뮤니케이션**

| 점수 | 기준 |
|---|---|
| 0 | 응답률 80% 미만 또는 확인 불가 |
| 3 | 응답률 90% 이상. 프로필 안에 응답 관련 언급 없음 |
| 5 | 응답률 95% 이상. 프로필에 "24시간 내 답변" 등 구체 언급 있음 |

---

**5. 영상·강의·화면녹화 샘플**

| 점수 | 기준 |
|---|---|
| 0 | 샘플 영상 0편. 텍스트 설명만 있음 |
| 3 | 샘플 1편 있으나 파일럿 #1 주제와 거리 있음 (예: 포토샵 강의 샘플) |
| 5 | AI·자동화·Notion 관련 샘플 1편 이상. 설명 속도·화면 구성·음질 양호 확인 가능 |

---

**6. 1인 사업가 대상 설명력**

| 점수 | 기준 |
|---|---|
| 0 | 타깃이 개발자·대기업 직원. 1인 사업가 맥락 언급 없음 |
| 3 | 프리랜서·소규모 팀 언급 있으나 1인 사업가 특화는 아님 |
| 5 | 프로필·샘플에서 "1인 사업가", "프리랜서", "혼자 다 하는 사람" 맥락으로 설명 가능 확인됨 |

---

**7. B등급 예산 협업 가능성 (추정)**

| 점수 | 기준 |
|---|---|
| 0 | 프로필 기준 편당 80만 원 초과 추정 (C등급) — 이 단계에서 실제 가격 제안 X, 추정만 |
| 3 | 편당 30~80만 원 범위 내 추정 가능. 크몽 기존 의뢰 가격대 참고 |
| 5 | 프로필에 B등급 범위 내 가격대 명시 또는 유사 의뢰 후기에서 확인 가능 |

⚠️ 이 항목은 *추정*이다. 실제 가격 제안·협상은 Step 7 이후 회원이 직접 한다.

---

**8. Notion·ChatGPT·Claude 실무 경험 (파일럿 특화)**

| 점수 | 기준 |
|---|---|
| 0 | 파일럿 #1 도구 언급 없음 |
| 3 | 1~2개 도구 경험 언급 있으나 강의로 연결한 사례 없음 |
| 5 | ChatGPT·Notion·Claude·Make·Zapier 중 2개 이상 실무 활용 + 강의·튜토리얼 사례 확인 |

---

### 2.2 가산점 (4개 — 각 +1점)

- [ ] +1: 초보자 또는 비개발자 대상 강의 경험 확인
- [ ] +1: 템플릿·시스템 구축 납품 사례 (Notion DB, Make 시나리오 등) 보유
- [ ] +1: 판매용 강의 협업 의사 — 프로필 또는 이전 의뢰 설명에서 "강의 제작·판매" 관련 언급
- [ ] +1: 6편 패키지 또는 1회 자문+촬영 협업 형태 경험 있음

## 3. 후보 접촉 *준비* 체크리스트 (메시지 발송 *전*)

회원이 D7 이후 Step 8로 넘어가기 *전*에 손에 있어야 하는 것들이다.
이 단계(Step 6)에서는 *확인 목록*만 공유한다.

- [ ] 발신자 소개 1~2줄 — "Core Campus가 어떤 사이트인지, 누가 운영하는지" 1~2문장
- [ ] 발견 경위 메모 — 후보별로 "이 콘텐츠·이 프로필을 보고 연락했다"고 쓸 수 있는 *구체적 콘텐츠 1개* 미리 캡처·메모
- [ ] 첨부 자료 (선택) — 파일럿 #1 설계서 중 주제·타깃·차시 구조 1장 발췌본
- [ ] 답신 받았을 때 보낼 후속 안내문 — 견적·일정·샘플 요청 4개 항목 (Step 8에서 작성)
- [ ] 정책 §10.6 사용권 한 줄 요약 — "저작권은 양도 아님, Core Campus 전용 사용권 3년, 수정·마케팅 발췌 허용" 수준의 1줄

⚠️ 실제 메시지 본문은 본 키트에 포함하지 않는다 — Step 7 평가 완료 후 Step 8에서 작성한다.
