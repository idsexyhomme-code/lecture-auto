## 2. 후보 평가표 템플릿

### 2.1 평가 항목 8개 (0~5점)

각 항목 0점·3점·5점 기준을 아래에 명시한다. 중간값(1·2·4)은 기준 사이에서 회원이 판단.

---

**1. 관련 실무 경험·포트폴리오**

| 점수 | 기준 |
|---|---|
| 0 | 포트폴리오 없음. 설명만 있고 결과물 없음 |
| 3 | 강의 또는 컨설팅 결과물 1~2개 공개. 업종 무관 |
| 5 | AI·자동화·Notion 관련 강의 또는 프로젝트 결과물 3개 이상 공개 |

---

**2. 후기 수·외부 신뢰 자료**

| 점수 | 기준 |
|---|---|
| 0 | 후기 없음 또는 9개 이하 |
| 3 | 후기 10~19개. 내용 평이 |
| 5 | 후기 20개 이상. "실무에 바로 썼다" 류의 구체 후기 포함 |

---

**3. 평점·신뢰도**

| 점수 | 기준 |
|---|---|
| 0 | 평점 4.4 이하 또는 없음 |
| 3 | 평점 4.5~4.6 |
| 5 | 평점 4.7 이상 |

---

**4. 응답 속도·커뮤니케이션**

| 점수 | 기준 |
|---|---|
| 0 | 응답률 80% 이하. 평균 응답 3일 초과 |
| 3 | 응답률 80~89%. 평균 1~2일 |
| 5 | 응답률 90% 이상. 평균 당일~24시간 이내 |

---

**5. 영상·강의·화면녹화 샘플**

| 점수 | 기준 |
|---|---|
| 0 | 샘플 없음 |
| 3 | 샘플 1편. 화질·음질 보통. 화면 녹화 또는 슬라이드 위주 |
| 5 | 샘플 2편 이상. 화질·음질 양호. 강사 직접 설명 방식 포함 |

---

**6. 1인 사업가 대상 설명력**

| 점수 | 기준 |
|---|---|
| 0 | 설명이 IT 개발자 또는 기업 전산팀 기준. 비전공자 배려 없음 |
| 3 | 일반인 대상 설명 시도. 용어 풀어쓰기 일부 |
| 5 | 비전공 1인 사업가·프리랜서를 명시적으로 언급. 예시·화면 클릭 중심 설명 |

---

**7. B등급 예산 협업 가능성**

| 점수 | 기준 |
|---|---|
| 0 | 공개 단가가 80만 원 초과. 패키지 없음 |
| 3 | 공개 단가 30~80만 원 범위 내. 패키지 언급 없음 |
| 5 | 공개 단가 30~80만 원 범위 내. 복수 편 패키지 또는 협의 가능 명시 |

*주의: 이 항목은 공개된 정보만 확인. 가격 제안·협상 X.*

---

**8. Notion·ChatGPT·Claude 실무 경험 (파일럿 특화)**

| 점수 | 기준 |
|---|---|
| 0 | 파일럿 대상 툴(Notion·ChatGPT·Claude·Make·Zapier) 중 언급 없음 |

## 3. 후보 접촉 *준비* 체크리스트 (메시지 발송 *전*)

회원이 Step 7 평가 완료 후, 메시지 발송 전에 손에 있어야 하는 것.

- [ ] 발신자 소개 1~2줄 — Core Campus가 어떤 사이트인지, 누구를 위한 곳인지 한 문단
- [ ] 발견 경위 — 후보별로 *구체적 콘텐츠 1개* 이름·링크 또는 제목 메모해두기 (샘플 영상 제목, 후기에 언급된 프로젝트명 등)
- [ ] 첨부 자료 — 파일럿 설계서 발췌 1장 (주제·타깃·차시 구조·납기 요약본. Step 7 이후 CEO가 준비)
- [ ] 답신 받았을 때 보낼 후속 안내문 — 견적·일정·샘플 확인 요청 메시지 초안 (Step 8에서 작성)
- [ ] 정책 §10.6 사용권 한 줄 요약 — "영상 사용권은 Core Campus 전용 3년 / 수정 1회 / 제3자 양도 없음"

⚠️ 실제 메시지 본문은 본 키트에 포함 X — Step 7 평가 후 Step 8에서 작성.

## 5. CEO 자율 작업 (회원 검색 결과 받은 후)

아래는 회원이 D6에 후보 5명 정보를 전달하는 즉시 CEO가 *승인 없이* 바로 진행한다.

- 후보 5명 §2.5 평가표 점수 채우기
- 각 후보 프로필 요약 한 단락 (채널·전문 분야·후기 수·평점·파일럿 적합도 포함)
- 합격·탈락 근거 항목별 명시
- 빨간 깃발 자동 검출 → 탈락 후보 즉시 분리
- 합격 후보 중 추천 1명 선정 + 근거 1단락 작성
