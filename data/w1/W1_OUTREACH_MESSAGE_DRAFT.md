권리 조건은 전용 사용권 3년·일시불 기준 표준 계약서로 진행합니다. 문서는 따로 드리겠습니다.

아래 네 가지 확인 부탁드립니다.

① 1안 또는 2안 가능 여부
② 견적
③ 가능한 일정
④ 기존 샘플 영상 1편 링크

## 5. 회원에게 — 발송 전 체크리스트

> 이 섹션은 회원님 확인용입니다. CEO가 대신 실행하지 않습니다.

### 발송 전 필수 확인 5가지

```
□ 1. 발송 채널 확인
      크몽 플랫폼 내부 메시지 기능으로 직접 발송.
      외부 채널(카카오·이메일·DM) 사용 금지.

□ 2. v1 / v2 선택
      → 6편 제안에 자신 있으면 v1
      → 상대가 신인이거나 검증이 덜 됐으면 v2 (파일럿 1편 옵션)

□ 3. Placeholder 3개 채우기
      → [전문가 콘텐츠 제목]: 실제 본 영상·글 제목 정확히 입력
      → [구체 칭찬 1줄]: "몇 편에서 어떤 장면이 좋았다" 식으로
      → [N일]: 3~5일 권장. 7일 넘기면 답신율 떨어짐.

□ 4. 첨부 파일 (선택)
      → 이번 W1 파일럿에서는 첨부 없이 발송해도 무방.
      → 계약 조항 PDF가 준비됐으면 "문서 드리겠습니다" 대신 바로 첨부 가능.

□ 5. §10.4 기준 재확인
      → 평점 4.7 이상 / 후기 20개 이상 / 응답률 90% 이상
      → 위 세 조건 중 하나라도 미달이면 발송 보류.
         CEO에게 재평가 요청.
```

### CEO가 이미 처리한 것

- 메시지 초안 2종 (v1 / v2)

- §10.5 6단 구조 준수 확인

### ★ 회원 승인 필수 — 발송은 회원이 직접

CEO는 메시지 *초안*까지만 생성합니다.
