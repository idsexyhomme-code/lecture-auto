## 촬영 방식 결정 가이드

### 비교표

| 방식 | 장점 | 단점 | B등급 예산 적합도 |
|---|---|---|---|
| **화면녹화** | 편집 최소. 전문가 환경 그대로. 녹화·재녹화 자유. 편당 단가 낮음. | 화자 얼굴 없으면 신뢰감 낮아질 수 있음. 설명 밀도 높아야 함. | ★★★ 가장 적합 |
| **줌 인터뷰** | 얼굴 노출로 신뢰 상승. 추가 장비 불필요. 원격 진행 가능. | 인터넷 품질에 좌우됨. 화질 720p 한계. 대화 흐름 끊기면 편집 증가. | ★★☆ 적합 (조건부) |
| **간단 대면** | 화질·음질 최상. 강사 에너지 전달. 수강생 신뢰도 높음. | 스튜디오·조명·마이크 비용 추가. 일정 조율 필요. 이동 시간 발생. | ★☆☆ 예산 초과 위험 |

### B등급 예산 (총 50~150만 원) 추천 조합

```
1순위: 화면녹화 + 줌 인트로 30초 (얼굴 신뢰 + 비용 절감 동시에)
  - 편당 구성: 줌으로 강사 얼굴 30초 인사 → 화면녹화로 본 강의
  - 예상 단가: 편당 30~50만 원 × 6편 = 180~300만 원
  → 예산 초과 가능. 6편 중 3편 먼저 제작 후 2차 계약 추천.

2순위: 화면녹화 단독 (편집 최소화 + 납기 4주 준수에 유리)
  - 편당 단가: 25~40만 원 × 6편 = 150~240만 원
  → 총예산 상한 150만 원 맞추려면 편당 25만 원 이하 협상 필요.
  → 또는 6편 중 파일럿 2편만 먼저 계약.

3순위: 줌 인터뷰 단독 (대면 이동 없이 신뢰 확보)
  - 편당 단가: 30~60만 원. 편집 시간 변수 큼.
  → 전문가에게 "줌 원본 납품 + 자막 직접 처리" 조건으로 단가 낮출 것.
```

**CEO 추천: 파일럿 2편 화면녹화 단독 → 수강생 반응 확인 → 나머지 4편 방식 결정.**
6편 한꺼번에 계약하면 예산 초과 위험 있음. 분할 계약이 리스크가 작다.
