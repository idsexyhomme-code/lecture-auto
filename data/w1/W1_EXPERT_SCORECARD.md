## 1. 평가 항목 8개

### 항목 1 — 실무 경험

> 강의 주제를 실제로 써본 사람인가.

| 점수 | 상태 |
|---|---|
| **0점** | 실무 경험 없음. 이론·자격증만 언급. 포트폴리오에 본인 사업·업무 흔적 없음. |
| **3점** | 직장 경력 or 프리랜서 경험 있음. 구체적 숫자(기간·규모·건수) 일부 확인. |
| **5점** | 직접 운영한 사업·서비스·고객 사례가 수치로 증명됨. "내가 해봤다"가 명확. |

**검증 방법**
- 크몽·숨고 자기소개 + 포트폴리오 탭 직접 확인
- LinkedIn 프로필의 '경력' 섹션 (현직 or 최근 3년 이내 실무)
- SNS·블로그에 본인 작업물 공개 여부

---

### 항목 2 — 설명력

> 말하는 방식이 수강생 눈높이에 맞는가. 쉽게 설명하는가.

| 점수 | 상태 |
|---|---|
| **0점** | 샘플 영상 없음. or 전문 용어 나열·속도 불규칙·중간 끊김 심각. |
| **3점** | 전달은 되지만 군더더기 많거나 설명이 교과서식. 수강생이 한 번에 이해하기 어려움. |
| **5점** | 개념 1개를 일상 사례로 바로 연결. 30초 안에 핵심이 들린다. 속도·발음·문장 흐름 자연스러움. |

**검증 방법**
- 크몽·숨고 샘플 영상 1분 30초 이상 청취
- 유튜브·SNS 강의 클립 있으면 추가 확인
- 설명 도중 "즉", "쉽게 말하면", "예를 들어" 빈도 체크

---

### 항목 3 — 포트폴리오 신뢰도

> 실제 납품 결과물이 확인 가능한가. 허위·과장이 없는가.

| 점수 | 상태 |
|---|---|
| **0점** | 포트폴리오 없음. or 링크 깨짐. or 타인 작업물 도용 의심. |
| **3점** | 1~2편 있음. 제목·썸네일 수준 확인 가능. 납품 조건·내용은 모호함. |
| **5점** | 3편 이상. 주제·분량·납기·후기가 결과물과 일치. 실명 or 채널 기반 결과물 검색 가능. |

**검증 방법**
- 크몽·숨고 '포트폴리오' 탭 전수 확인
- 후기 내용과 포트폴리오 주제 매칭 여부 교차 확인
- Google 검색: 강사명 + 강의 제목 or 채널명

---

### 항목 4 — 1인 사업가 타깃 적합성

> Core Campus 수강생(1인 사업가·프리랜서·크리에이터)을 직접 상대해본 경험이 있는가.

| 점수 | 상태 |
|---|---|
| **0점** | 대기업·공공기관 전용 경력. 1인 사업·프리랜서 관련 언급 전무. |
| **3점** | 일반 직장인 대상 강의 경험. 1인 사업 관련 언급은 부분적. |
| **5점** | 1인 사업가·프리랜서·크리에이터를 직접 가르친 강의 or 컨설팅 실적 확인. 후기에 "대표님", "프리랜서", "부업" 등 타깃 키워드 등장. |

**검증 방법**
- 후기 전문 읽기 — 수강자 직함·상황 확인
- 강사 자기소개에 "사업주", "1인", "부업", "프리랜서" 키워드 포함 여부
- 본인 SNS 팔로워층 or 블로그 댓글 성격 확인

---

### 항목 5 — 화면녹화·강의 가능성

> 줌·OBS·화면녹화 기반 비대면 강의 영상을 만들 수 있는가.

| 점수 | 상태 |
|---|---|
| **0점** | 오프라인 강의·대면 세션만 경험. 녹화 영상 전무. |
| **3점** | 줌 or 화면녹화 경험 있음. 편집 없이 원본 납품 가능 수준. 화질·음질 보통. |
| **5점** | 화면녹화·자막·인트로·챕터 구분 영상 납품 이력 있음. 장비(마이크·캡처보드 or 소프트웨어) 보유 명시. |

**검증 방법**
- 크몽 서비스 설명에 "녹화", "줌", "OBS", "Loom", "화면공유" 언급 여부
- 샘플 영상 화질(720p 이상) / 마이크 잡음 / 화면 구성 직접 확인
- 납품 형식(mp4 / mov / 자막 포함 여부) 명시 여부

### 항목 6 — 협업 가능성

> 피드백을 받아들이고 수정 요청에 실제로 대응하는가.

| 점수 | 상태 |
|---|---|
| **0점** | 응답률 80% 미만. 후기에 "소통 안 됨", "수정 거부" 패턴 등장. |
| **3점** | 응답률 90% 내외. 소통은 되지만 수정 범위 협의에 시간 걸림. |
| **5점** | 응답률 95% 이상. 후기에 "빠른 피드백", "꼼꼼한 수정", "일정 엄수" 패턴 반복. |

**검증 방법**
- 크몽·숨고 응답률 수치 직접 확인
- 최근 후기 10개 중 소통·수정 관련 언급 추출
- 자기소개에 "수정 1회 포함", "일정 협의 가능" 명시 여부

### 항목 7 — 예산 적합성

> B등급 기준(출연료 30~80만 원)에 실제로 맞는가.

| 점수 | 상태 |
|---|---|
| **0점** | 최저 견적이 80만 원 초과. or 명시 가격 없고 문의 후 안내 방식. |
| **3점** | 기본 패키지 30~80만 원 내. 단 추가 요청 시 초과 가능성 있음. |
| **5점** | 기본~중간 패키지가 B등급 내. 추가 옵션 금액도 명시돼 있어 예산 예측 가능. |

**검증 방법**
- 크몽·숨고 서비스 패키지 가격 직접 확인
- "기본 / 스탠다드 / 프리미엄" 구분 시 스탠다드 기준 금액 체크
- 분당·편당 단가 환산해서 총 제작비 시뮬레이션

### 항목 8 — Core Campus 브랜드 적합성

> 콘텐츠 톤이 과장 없이 실전·실무 중심인가. 자극적 부업팔이 톤이 없는가.

| 점수 | 상태 |
|---|---|
| **0점** | "하루 10분으로 월 천만 원", "폭발적 수익", "비밀 공개" 같은 카피 사용. |
| **3점** | 톤은 무난함. 단 일부 과장 수식어 사용 or 수익 인증 강조. |
| **5점** | 설명이 구체·수치 기반. 클릭베이트 없음. 헌법 §4 금기 패턴 없음. |

**검증 방법**
- 강사 SNS·블로그·유튜브 썸네일·제목 전수 확인
- 자기소개 문구 중 §4 금기 패턴("폭발적", "월 천만", "무조건") 검색
- 포트폴리오 강의 제목 스타일 — 자극형 vs 실무형 분류

## 2. 최종 합격 임계값

### 총점 기준

| 등급 | 총점 (40점 만점) | 처리 |
|---|---|---|
| **S** | 36~40점 | 즉시 섭외 메시지 초안 작성 요청 |
| **A** | 30~35점 | 회원 확인 후 섭외 진행 |
| **B** | 24~29점 | 보류 — 대안 후보 없을 때만 재검토 |
| **탈락** | 23점 이하 | 자동 제외 |

### 항목별 최소 점수

아래 항목 중 하나라도 **2점 이하**이면 총점 무관 자동 탈락.

| 항목 | 최소 점수 |
|---|---|
| 1. 실무 경험 | 3점 |
| 5. 화면녹화·강의 가능성 | 3점 |
| 6. 협업 가능성 | 3점 |
| 7. 예산 적합성 | 3점 |
| 8. Core Campus 브랜드 적합성 | 3점 |

> 나머지 3개 항목(설명력·포트폴리오·타깃 적합성)은 2점도 허용하되 총점으로 보완.

## 4. 빨간 깃발 — 자동 탈락 조건 5개

아래 중 **하나라도 해당**하면 평가 시트 작성 없이 즉시 제외.
CEO가 헌법 §10.4 기준 자동 적용.

| # | 조건 | 확인 위치 |
|---|---|---|
| 🚩 1 | 플랫폼 평점 **4.5 미만** | 크몽·숨고 프로필 상단 평점 수치 |
| 🚩 2 | 누적 후기 **10개 미만** | 프로필 후기 탭 총 건수 |
| 🚩 3 | 응답률 **80% 미만** | 크몽 서비스 정보 or 숨고 프로필 통계 |
| 🚩 4 | 공개 샘플 영상 **0편** | 포트폴리오 탭 + SNS 검색 후에도 없을 경우 |
| 🚩 5 | 분쟁 이력 or 내부 블랙리스트 등재 | experts_crm.json `status: blacklist` 필드 + 후기 중 "환불", "분쟁", "미납" 키워드 |

> **빨간 깃발 1개 = 탈락.** 예외 없음.
> 탈락 사유는 CRM `internal_notes` 필드에 한 줄 기록 후 `status: rejected` 처리.
