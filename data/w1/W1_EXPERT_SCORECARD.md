# W1 전문가 후보 평가 스코어카드

**Core Campus | 외주 전문가 선정 기준 v1**
작성일: 2026-05-15 | 적용 등급: B등급 (출연료 30~80만 원 / 월 한도 200만 원)

---

## 1. 평가 항목 8개

> 각 항목 0~5점. 소수점 없음. 평가자는 CEO 에이전트 — 최종 선택은 회원.

---

### 1. 실무 경험

**"이 사람이 직접 해봤는가?"**

| 점수 | 상태 |
|---|---|
| **0점** | 강의·콘텐츠 제작 경험 전무. 프로필에 직함만 있음. |
| **3점** | 직장인 부업·사이드 프로젝트 경험 있음. 수익화 여부 불명확. |
| **5점** | 1인 사업·프리랜서·크리에이터로 실제 수익 발생 이력 확인 가능. 구체 숫자 or 사례 공개됨. |

**검증 방법**
- 플랫폼 프로필 소개란 → "전 직장·현 직업" 확인
- 포트폴리오·링크 클릭 → 본인 운영 서비스·판매 페이지 존재 여부
- SNS·유튜브·블로그 → 최근 6개월 내 실무 콘텐츠 게시 여부

---

### 2. 설명력

**"처음 듣는 사람이 이해하는가?"**

| 점수 | 상태 |
|---|---|
| **0점** | 샘플 영상 없음. 또는 전문용어만 나열, 맥락 설명 없음. |
| **3점** | 설명은 되지만 속도·구조가 불안정. 중간에 흐름 끊김 1회 이상. |
| **5점** | 첫 60초 안에 핵심 전달 완료. 예시·숫자·일상 장면 포함. 듣는 즉시 따라할 수 있는 수준. |

**검증 방법**
- 샘플 영상 앞 3분만 시청 → 첫 60초 집중 청취
- "이게 뭔지 처음 보는 사람도 이해되는가?" 자문
- 유튜브·클래스101·인스타 릴스 등 공개 콘텐츠 동일 기준 적용

### 3. 포트폴리오 신뢰도

**"결과물이 실제로 존재하는가?"**

| 점수 | 상태 |
|---|---|
| **0점** | 포트폴리오 링크 없음. 또는 링크 열리지 않음. |
| **3점** | 이미지·캡처·슬라이드만 있음. 영상 결과물 없음. |
| **5점** | 영상 1편 이상 직접 시청 가능. 화질·사운드·자막 중 2개 이상 기준 충족. 납품 실적 후기와 일치. |

**검증 방법**
- 크몽·숨고 프로필 내 포트폴리오 탭 → 영상 직접 재생
- 링크드인 → 첨부 미디어 섹션
- 외부 링크(유튜브·드라이브·노션) 클릭 → 실제 재생 여부 확인

### 4. 1인 사업가 타깃 적합성

**"이 전문가의 말을 우리 수강생이 공감하는가?"**

| 점수 | 상태 |
|---|---|
| **0점** | 대기업·공공기관 전용 콘텐츠만 있음. 1인 사업가·프리랜서 관련 경험 없음. |
| **3점** | 일반 직장인 대상 콘텐츠 있음. 1인 사업가 특화는 아니지만 응용 가능. |
| **5점** | 강의·콘텐츠·서비스 주제가 1인 사업가·프리랜서·크리에이터 직접 타깃. 수강생 후기에 "저도 1인 사업 하는데" 등 언급 있음. |

**검증 방법**
- 크몽·숨고 서비스 제목·설명 → 타깃 명시 여부
- 수강생 후기 5개 이상 읽기 → 구매자 직업·상황 언급 확인
- SNS·블로그 → 팔로워·독자 반응 성격 확인

### 5. 화면녹화·줌·간단 대면 가능성

**"B등급 방식으로 찍을 수 있는가?"**

| 점수 | 상태 |
|---|---|
| **0점** | 스튜디오 촬영·고급 장비만 가능하다고 명시. 또는 화면녹화 경험 없음. |
| **3점** | 줌·OBS 등 사용 가능하지만 샘플이 없어 품질 미확인. |
| **5점** | 화면녹화·줌·간단 대면 방식 결과물 1편 이상 확인. 사운드 잡음 없음. 자막 or 자체 편집 포함. |

**검증 방법**
- 포트폴리오 영상 → 촬영 방식 육안 확인 (화면녹화 vs 카메라)
- 서비스 설명란 → "화면녹화 가능" "줌 강의 가능" 문구 확인
- 직접 질문 가능 (섭외 메시지 발송 후 ①번 항목으로 확인)

### 6. 협업 가능성

**"같이 일하면 문제가 생기는가?"**

| 점수 | 상태 |
|---|---|
| **0점** | 응답률 80% 미만. 또는 분쟁 이력·부정 후기 있음. |
| **3점** | 응답률 80~89%. 후기에 "납기 살짝 늦음" 1~2건. 치명적 문제는 없음. |
| **5점** | 응답률 90% 이상. 후기에 소통·납기 관련 긍정 언급 있음. 문의에 24시간 이내 답신 이력. |

**검증 방법**
- 크몽·숨고 프로필 → 응답률 수치 직접 확인
- 후기 전체 스캔 → "늦게", "연락 안 됨", "수정 안 해줌" 등 키워드 검색
- 최근 후기 3개 → 날짜 기준 최신 활동 여부 확인

### 7. 예산 적합성

**"B등급 범위 안에 들어오는가?"**

| 점수 | 상태 |
|---|---|
| **0점** | 최저 단가가 80만 원 초과. 또는 패키지 강제 구매만 가능. |
| **3점** | 단가 50~80만 원. 협상 여지 있음. 월 한도 200만 원 내 2편 가능. |

### 8. Core Campus 브랜드 적합성

**"이 사람의 톤이 우리 사이트와 어울리는가?"**

| 점수 | 상태 |
|---|---|
| **0점** | 자극적 동기부여·"하루 10분 월 1,000만 원" 류 표현 사용. 또는 정치·갈등 콘텐츠 이력. |
| **3점** | 톤이 무난함. 특별히 문제는 없지만 Core Campus 색과 동일하지 않음. |

**검증 방법**

- 강의 소개 문구 → 금지어 (§4·카피 원칙 [1]) 포함 여부 확인
- 부정적 이슈 검색: "전문가 이름 + 논란 / 사기 / 환불" 키워드 검색

## 4. 빨간 깃발 — 자동 탈락 조건 5개

아래 중 **하나라도** 해당하면 나머지 평가 없이 즉시 탈락. CRM `status: rejected` + `blacklist_reason` 기록.

| # | 조건 | 기준값 | 확인 위치 |
|---|---|---|---|
| 🚩 1 | 플랫폼 평점 낮음 | **4.5 미만** | 크몽·숨고 프로필 상단 별점 |
| 🚩 2 | 후기 수 부족 | **10개 미만** | 플랫폼 후기 탭 총 건수 |
| 🚩 3 | 응답률 낮음 | **80% 미만** | 크몽·숨고 프로필 응답률 수치 |
| 🚩 4 | 영상 샘플 없음 | **0편** | 포트폴리오 탭 + 외부 링크 |
| 🚩 5 | 분쟁 이력·블랙리스트 | 1건 이상 | 후기 내 분쟁 언급 + 내부 CRM blacklist 확인 |

> **§10.4 vs 본 문서 차이점 메모**
> 헌법 §10.4는 평점 4.7 이상·후기 20개 이상을 필수 기준으로 정한다.
> 본 빨간 깃발은 *최소 탈락 방어선*이다.
> 4.5~4.6점·후기 10~19개 후보는 탈락이 아니라 점수 감점(항목별 3점 처리) 후 총점으로 판단한다.
> **§10.4 기준(4.7 이상·20개 이상)을 충족해야 5점 만점 부여.**
