## 1. 적합한 전문가 유형

> 아래 6개 유형 중 **우선순위 높음** 2개를 먼저 찾는다. 나머지는 후보가 부족할 때 보충.

### 유형 1 — ChatGPT·Claude 업무 자동화 강사

| 항목 | 내용 |
|---|---|
| **역할** | ChatGPT·Claude를 실무에 붙이는 법을 가르치는 강사. 프롬프트 설계부터 업무 템플릿 적용까지. |
| **필수 경험** | 1인 사업가·프리랜서 대상 강의 이력. 수강 후기 20개 이상. 자신이 직접 써본 결과물 포트폴리오. |
| **우선순위** | ★★★ 높음 |
| **검색 키워드** | `ChatGPT 강의`, `Claude 업무 자동화`, `AI 프롬프트 강사` |

---

### 유형 2 — Notion 자동화 전문가

| 항목 | 내용 |
|---|---|
| **역할** | Notion 데이터베이스·자동화 기능으로 1인 사업 운영판 만드는 법 강의. 수강생이 보고 바로 따라 할 수 있는 화면 시연 중심. |
| **필수 경험** | Notion 템플릿 제작·판매 이력 또는 강의 제작 이력. 1인 사업가·팀 대상 컨설팅 경험. |
| **우선순위** | ★★★ 높음 |
| **검색 키워드** | `Notion 자동화`, `노션 강의`, `노션 1인 사업` |

---

### 유형 3 — Make·Zapier 자동화 전문가

| 항목 | 내용 |
|---|---|
| **역할** | Make(구 Integromat) 또는 Zapier로 반복 작업을 줄이는 법 강의. 영상 안에서 실제 시나리오를 직접 만들어 보여줌. |
| **필수 경험** | Make·Zapier 실무 적용 사례 2건 이상. 비개발자 대상 강의 경험 있으면 가산. |
| **우선순위** | ★★☆ 중간 |
| **검색 키워드** | `Make 자동화`, `Zapier 강의`, `업무 자동화 강사` |

---

### 유형 4 — 1인 사업가 생산성 컨설턴트

| 항목 | 내용 |
|---|---|
| **역할** | 실제로 1인 사업을 운영하면서 AI·툴을 붙여본 사람. 강사보다 실무자에 가까운 톤. "저는 이렇게 씁니다" 형식의 영상에 적합. |
| **필수 경험** | 본인이 1인 사업·프리랜서·크리에이터로 월 수입 발생 중. 블로그·SNS·유튜브에서 검증 가능한 이력. |
| **우선순위** | ★★☆ 중간 |
| **검색 키워드** | `1인 사업 강의`, `프리랜서 생산성`, `크리에이터 운영` |

---

### 유형 5 — AI 업무 시스템 구축 경험자

| 항목 | 내용 |
|---|---|
| **역할** | ChatGPT API·Notion·Make·Google Sheets를 묶어서 실제 업무 흐름을 만들어본 사람. 단순 툴 소개가 아니라 "시스템"을 보여줄 수 있어야 함. |
| **필수 경험** | API 연결 또는 자동화 시나리오 실제 구축 경험. 비개발자 대상 설명 가능한 언어 구사. |
| **우선순위** | ★★☆ 중간 |
| **검색 키워드** | `AI 업무 시스템`, `GPT API 자동화`, `노코드 자동화 강사` |

---

### 유형 6 — 디지털 상품·강의 제작 경험자

| 항목 | 내용 |
|---|---|
| **역할** | 전자책·강의·템플릿 등 디지털 상품을 직접 만들고 판 경험이 있는 사람. "AI로 디지털 상품 만들기" 차시에 투입. |
| **필수 경험** | 디지털 상품 실제 판매 이력. 강의 플랫폼(클래스101·탈잉·크몽 등) 등록 이력. |
| **우선순위** | ★☆☆ 낮음 (보충용) |
| **검색 키워드** | `디지털 상품 만들기`, `전자책 강의`, `온라인 강의 제작` |
