## 1. 파일럿 #1 개요

- **프로젝트 코드명**: PILOT-01
- **목표**: Core Campus 첫 외부 전문가 강의 1건 사이트 등록 + 첫 결제 3건
- **기간**: 4주 (D1~D30)
- **총예산 상한**: 150만 원 (정책 §10.4 B등급 월 한도)
- **1순위 채널**: 크몽 / 백업: 숨고
- **회원 결정 기준일**: 2026-05-15

**이 파일럿이 검증하려는 가설**
외부 전문가 1인과 4주 안에 영상 6편을 만들어 사이트에 등록하고 결제 3건을 받는 것이 가능한가. 현재 Core Campus의 섭외→계약→검수→등록 파이프라인이 정책 §10 범위 안에서 실제로 작동하는지 확인한다. 파일럿 종료 후 깨진 지점 1~2개를 찾아 정책 v2에 반영한다.

## 2. 강의 구조 — Step 1·2 결정값 통합

- **주제**: 1인 사업가를 위한 AI 업무 자동화 입문
- **활용 도구**: ChatGPT · Claude · Notion · Make/Zapier (우선순위는 Step 2 추천에 따름)
- **차시**: 6편 × 12~15분
- **타깃**: AI로 자기 사업·강의·콘텐츠·자동화 시스템을 만들고 싶은 1인 사업가·프리랜서·크리에이터

**약속할 결과** (Step 2 표현 인용)
강의를 다 보고 나면 ChatGPT·Claude·Notion·Make 중 본인 사업에 바로 쓸 수 있는 도구 1개를 골라 실제 업무에 붙일 수 있다.

**하지 않을 것** (Step 2 표현 인용)
모든 도구를 완벽하게 다 가르치지 않는다. AI가 모든 것을 알아서 해준다는 식으로 말하지 않는다. 수익 보장·자동화 완성 같은 결과를 약속하지 않는다.

*커리큘럼 세부 차시 내용은 본 설계서에 포함하지 않는다 — 다음 step에서 별도 작성.*

## 3. 외부 전문가 프로필 요구

### 필수 (모두 충족해야 후보 등록)

| # | 기준 | 임계값 |
|---|---|---|
| 1 | 플랫폼 평점 | 4.7 이상 |
| 2 | 누적 후기 수 | 10개 이상 (파일럿 특화 — 정책 기본값 20에서 10으로 하향, 추정 조정 1차 안) |
| 3 | 응답률 | 90% 이상 |
| 4 | 활동 기간 | 6개월 이상 |
| 5 | 영상 샘플 공개 여부 | 1편 이상 |
| 6 | 6편 패키지 납품 이력 또는 단편 다수 납품 이력 | 있음 |
| 7 | 강의·교육 콘텐츠 제작 경험 | 있음 |
| 추가-1 | Notion / ChatGPT / Claude 중 최소 2개 실무 경험 | 프로필·샘플에서 확인 가능해야 함 |
| 추가-2 | 6편 패키지 또는 1회 자문+촬영 모두 협업 가능 의사 | 프로필 또는 서비스 설명에서 확인 |

> ⚠️ 후기 수 임계값을 정책 기본값 20에서 10으로 조정한 것은 파일럿 1차 안(추정). 회원 별도 지시 없으면 이 값을 적용한다.

### 가산점 (우선순위에 반영)

| # | 항목 |
|---|---|
| 가산-1 | 결과 사례·포트폴리오 보유 |
| 가산-2 | Core Campus 타깃(1인 사업가·크리에이터) 강의 경험 |
| 가산-3 | 본인 SNS·블로그·유튜브 운영 (콘텐츠 톤 확인 가능) |
| 가산-4 | AI 관련 강의·콘텐츠 직접 제작 이력 |

### 합격선

- 필수 7개 + 추가 2개 → 전부 충족
- 가산점 최소 2개 이상
- 평점 4.7↑ / 후기 10↑

## 5. 산출물 체크리스트 (4주 누적)

- [ ] 외부 전문가 1명 계약 체결 (평가표·접촉 로그·계약서 포함)
- [ ] 강의 영상 6편 (각 12~15분, 1차 검수 + 회원 최종 검수 통과)
- [ ] 코스 상세페이지 1장 (헤드라인·약속·커리큘럼 구조·FAQ)
- [ ] 썸네일 시안 3개 (회원 ✅ 1개 선정)
- [ ] 결제 페이지 1개 (가격·환불 정책 포함, 회원 ✅)
- [ ] 권리 동의서 서명본 (정책 §10.6 10개 사용권 항목 확인·서명)
- [ ] 사이트 등록 완료 (코스 ID·카테고리 확정)
- [ ] 첫 결제 3건 + 후기 1개 수집
- [ ] 30일 회고 KPI 리포트
- [ ] 파일럿 #2 인사이트 메모

## 6. 검증 KPI (성공·실패 기준)

### 성공 기준 (모두 충족 시 파일럿 #2 진행)

- 영상 6편 D30 이전 완성
- 사이트 등록 + 결제 페이지 공개
- 첫 결제 3건 발생
- 헌법 §4 금기·§10 정책 위반 0회
- 전문가와의 분쟁 0건

### 실패 기준 (하나라도 발생 시 즉시 멈춤 + 회원 회의 소집)

- D30까지 영상 6편 완성 못 함
- 헌법 §4 절대 금지 항목 중 1개라도 위반
- 전문가 계약 분쟁 발생
- 총 예산 150만 원 초과 위험 감지 (초과 전 CEO 자동 경보)

## 7. 리스크 + 방지책 (5개)

| 리스크 | 영향 | 방지책 |
|---|---|---|
| 후보 5명 안에 합격선 충족자 0명 | 일정 지연 | D7까지 합격 후보 1명 없으면 숨고 백업 채널 즉시 전환. CEO가 추가 검색 키워드 3개 재추천. |

| 납품 영상 품질 미달 | 검수 실패 | 정책 §10.6 §7 — 납품 후 30일 이내 1회 무료 수정 발동. CEO 1차 검수에서 §4 금기·§8 톤 기준 항목별 체크리스트 적용. |

| D30 기준 첫 결제 0건 | 검증 실패 | D30 직후 즉시 회고 → 타깃·약속·가격·상세페이지 카피 4개 항목 재검토. 파일럿 #2 진행 여부는 회원 결정. |
