Claude 요금제, 1인 사업가는 어떤 걸 써야 할까

월 2만 원 낼지, 무료로 쓸지 — 아직도 Claude 요금제 헷갈리면

Claude 써보고 싶은데 요금 페이지 열었다가 그냥 창 닫은 적 있죠. Pro가 20달러인지 25달러인지, 무료랑 뭐가 다른지, 팀 플랜은 언제 필요한지 — 5분 보다가 "그냥 무료로 써보지 뭐" 하고 덮어버리는 그 장면. 사실 저도 그랬습니다.

왜 이게 어려운지

Anthropic 요금 페이지는 영어로 되어 있고, '매월 사용량 제한'이 정확히 몇 회인지 숫자로 안 씁니다. "Limited access" vs "Priority access" — 이게 실제로 얼마나 차이 나는지 설명이 없어요. 그러니까 무료 쓰다가 막히면 Pro 결제하면 되는 건지, 아니면 처음부터 Pro 써야 하는 건지 감이 안 옵니다.

팀 플랜은 더 심합니다. 1인 사업자인데 "팀 플랜이 나한테 해당되나?" 싶어서 넘겨버리게 됩니다. 실제로는 혼자 쓰면서 Claude 계정 여러 개 쓰고 싶은 분한테 팀 플랜이 맞는 경우도 있는데, 그 판단을 요금 페이지만 보고 하기가 어렵습니다.

결국 "일단 무료로 해보고 필요하면 올리지"가 되는데, 무료 계정으로 쓰다가 딱 필요한 순간에 "메시지 한도를 초과했습니다" 뜨면 그날 작업이 멈춥니다. 그 경험 한 번 하면 "그냥 처음부터 Pro 할 걸" 하게 되죠.

Claude 요금제, 이렇게 5단계로 정리하면 됩니다

요금 페이지를 처음부터 읽으려 하지 말고, 내 상황에 맞는 질문 순서로 접근하면 10분 안에 결론 납니다.

  • 1단계 — 하루에 Claude를 몇 번 쓰나 세어보기 하루 5번 이하면 무료로 충분합니다. 10번 넘어가면 Pro 검토하세요. 기준이 '하루 몇 번'이라는 게 핵심입니다.
  • 2단계 — 무료 계정으로 3일 먼저 써보기 막히는 날이 오는지 확인합니다. 한도 초과 메시지가 한 번도 안 뜨면 무료로 충분합니다. 이틀 안에 뜨면 Pro 결제합니다.
  • 3단계 — Pro 20달러가 아깝지 않은 조건 확인하기 업무용으로 하루 1시간 이상 Claude 쓰고, 한도 초과로 작업이 멈추는 게 한 달에 2번 이상이면 Pro 가성비가 맞습니다. 하루 30분 미만이면 무료로 버팁니다.
  • 4단계 — 팀 플랜은 이 경우만 보기 직원이 있거나, 외주 작가·디자이너한테 Claude 계정 공유해야 하는 경우입니다. 혼자 쓴다면 팀 플랜은 건너뜁니다.
  • 5단계 — API 쓸지 말지 결정하기 노션, 구글시트, 자체 서비스에 Claude를 붙이고 싶다면 API 요금제 따로 있습니다. 그냥 채팅창에서 쓸 거라면 API는 지금 신경 안 써도 됩니다.

이게 작동하는 이유

요금제 고민은 사실 정보 부족이 아닙니다. 요금 페이지에 정보는 다 있는데, 내 상황에 맞는 판단 기준이 없어서 헷갈리는 겁니다. 위 순서는 "지금 나한테 필요한 게 뭔지"를 먼저 잡고, 거기에 맞는 플랜을 역으로 찾아가는 방식입니다. 영어 페이지 처음부터 번역하면서 읽는 것보다 결론이 빠릅니다.

두 번째로, 3일 무료 테스트를 먼저 하면 돈 쓰고 후회하는 일이 없습니다. Pro 결제하고 "생각보다 별로 안 쓰네"가 되는 경우의 절반은, 3일만 먼저 써봤어도 막을 수 있었습니다.
