#5 편집 없이 자막만 붙인다lecture_script

코스: test-1tier-upgrade-1779174833 · 에이전트: producer

HOOK (45초)

영상 찍었는데 자막이 없습니다. 편집 툴 배우다가 이틀이 날아갔습니다. 그냥 자막 하나 붙이려고요. 그게 이렇게 오래 걸려야 하나요?

CapCut 자동 자막 기능, 딱 3분이면 끝납니다. 오늘 이 영상 보고 나면 찍어둔 파일에 바로 자막 붙입니다.

PROMISE (30초)

이 차시가 끝나면 CapCut으로 영상 1편에 자막을 입히고 1080p 파일로 저장할 수 있습니다.

CORE (8–10분)

개념 1 — CapCut 자동 자막 경로

설명 CapCut 앱을 켭니다. 하단 메뉴 순서는 이겁니다. 편집 → 텍스트 → 자동 자막. 세 번 탭입니다.

페그 이미지를 하나 드립니다. "엘리베이터 3층" 입니다. 1층 편집, 2층 텍스트, 3층 자동 자막. 이 순서 잊으면 다시 엘리베이터 탑니다.

예시 60초짜리 인터뷰 영상을 올렸습니다. 자동 자막 버튼 누르고 12초 기다렸습니다. 자막 65개가 자동으로 붙었습니다.

반례 배경 음악이 너무 크면 인식이 떨어집니다. 목소리보다 음악이 크게 녹음된 영상은 자막 정확도가 40% 아래로 내려갑니다. 찍을 때 목소리를 크게, 음악은 나중에 깔아야 합니다.

정리 편집 → 텍스트 → 자동 자막. 엘리베이터 3층입니다.

개념 2 — 자막 오류 수정 3곳

설명 자동 자막은 틀립니다. 제 경험상 65개 중 8개에서 12개는 오타가 납니다. 다 고칠 필요 없습니다. 딱 3곳만 잡으면 됩니다.

페그 숫자는 "3" 입니다. ① 고유명사 — 브랜드명, 사람 이름 ② 숫자 — 금액, 날짜 ③ 문장 첫 글자 — 소문자로 잘려 나옵니다

예시 "캡컷"이 "캐컷"으로 찍혔습니다. "2,000원"이 "이천 원"으로 풀어 써졌습니다. "오늘은"이 "오늘 은"으로 띄어 쓰였습니다. 이 3개만 손봐도 영상이 깔끔합니다.

반례 조사 오류는 그냥 두는 경우가 많습니다. "을/를" 헷갈리는 건 시청자가 크게 신경 쓰지 않습니다. 고치다가 시간 다 씁니다. 완벽하게 고치려다 업로드 못 합니다.

정리 고유명사, 숫자, 문장 첫 글자. 딱 3곳입니다.

개념 3 — 파일 저장 해상도 설정

설명 자막 다 됐으면 저장합니다. 오른쪽 상단 화살표 버튼 누릅니다. 해상도 옵션 3가지가 뜹니다. 720p, 1080p, 4K.

페그 이미지는 "유튜브 기준 TV 화면" 입니다. 유튜브 권장은 1080p입니다. 4K는 파일이 커서 업로드 오래 걸립니다. 720p는 흐립니다. 1080p 딱 하나만 기억합니다.

예시 60초 영상 기준으로 봤을 때 1080p 파일 크기는 대략 80MB입니다. 저장 시간은 20초에서 40초 사이입니다.

반례 쇼츠나 릴스는 720p도 괜찮습니다. 화면이 작아서 차이가 잘 안 보입니다. 하지만 나중에 다시 편집할 가능성이 있으면 1080p로 원본을 남겨둡니다.

정리 오른쪽 상단 화살표 → 1080p 선택 → 저장. 이 순서입니다.

EXERCISE (3–4분)

영상 잠깐 멈추세요. 지금 바로 따라 합니다. 4단계입니다.

1단계 — 영상 불러오기 CapCut 켜고 새 프로젝트 만듭니다. 30초에서 60초 사이 영상 하나 고릅니다. 없으면 오늘 찍은 영상 그대로 씁니다.

2단계 — 자동 자막 붙이기 편집 → 텍스트 → 자동 자막 누릅니다. 언어 한국어 선택하고 확인 누릅니다. 자막이 다 붙을 때까지 기다립니다.

3단계 — 오류 3곳 수정하기 자막 타임라인을 쭉 훑습니다. 고유명사, 숫자, 문장 첫 글자만 봅니다. 틀린 곳 눌러서 바로 고칩니다.

4단계 — 1080p로 저장하기 오른쪽 상단 화살표 누릅니다. 해상도 1080p 선택합니다. 저장 버튼 누르고 파일 확인합니다.

파일이 카메라 롤에 저장됐으면 됩니다. 영상 다시 켜세요.

CTA (30초)

파일 저장까지 됐으면 오늘 끝입니다.

다음 차시는 이겁니다. 완성된 영상, 어디에 올리면 돈이 됩니까? 플랫폼별 업로드 세팅을 딱 3가지로 정리합니다.

댓글에 저장한 영상 파일명 하나만 써두세요. "완료"라고만 써도 됩니다. 그게 제일 빠른 복습입니다.

예상 분량: 15분
