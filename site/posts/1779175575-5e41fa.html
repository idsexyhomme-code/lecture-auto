#11 영상 끝에 구매 링크 넣는다lecture_script

코스: test-1tier-upgrade-1779174833 · 에이전트: producer

HOOK (45초)

영상 올렸는데 조회수는 나오는데 매출은 0원.

댓글에 "어디서 살 수 있어요?" 달려도 그냥 지나쳤죠.

솔직히 링크 하나 없어서 그런 겁니다.

오늘 이 영상 끝나면 설명란에 구매 링크 박고, 자막에도 CTA 넣고, 클릭 수까지 확인합니다.

PROMISE (30초)

이번 차시가 끝나면 유튜브·릴스 영상 설명란에 클릭 가능한 구매 링크를 직접 써 넣고, 첫 번째 클릭이 들어왔는지 숫자로 확인할 수 있습니다.

CORE (8–10분)

개념 1 — CTA 위치 3곳

설명

링크를 넣을 수 있는 자리는 딱 3곳입니다.

① 설명란 첫 줄, ② 영상 자막 끝 3초, ③ 고정 댓글.

이 3곳을 저는 '삼각편대'라고 부릅니다.

전투기 편대처럼, 하나 놓쳐도 나머지 둘이 잡습니다.

예시

유튜브 영상 하나에 설명란 첫 줄에 링크 1개, 영상 끝 자막에 "지금 구경하기 → bit.ly/xxx", 고정 댓글에 같은 링크. 이렇게 3개 배치하면 클릭 경로가 3개 생깁니다.

반례

설명란 중간에 링크 묻어두면 아무도 찾지 않습니다.

스마트폰에서 더보기를 눌러야 보이는 위치는 클릭률이 뚝 떨어집니다.

실제로 제 경험상 같은 링크를 첫 줄 vs. 세 번째 줄에 뒀을 때 클릭 차이가 2배 났습니다.

정리

삼각편대 — 설명란 첫 줄 / 자막 끝 3초 / 고정 댓글. 위치가 곧 돈입니다.

개념 2 — 링크 단축 도구

설명

긴 링크 그대로 쓰면 보기도 싫고 클릭하기도 겁납니다.

단축 링크 도구 2가지만 씁니다.

① 비트리(Bitly) — 무료, 클릭 수 추적 가능. ② 스마트스토어·크몽이라면 플랫폼 자체 링크를 그대로 쓰되 UTM 파라미터를 붙입니다.

이건 '번호판'입니다. 어떤 영상에서 클릭이 왔는지 번호판 보듯 바로 압니다.

예시

bit.ly/내상품11 — 이렇게 끝에 차시 번호 붙이면, 영상 11편에서 온 클릭인지 12편에서 온 클릭인지 대시보드에서 바로 구분됩니다.

반례

링크 단축 없이 스마트스토어 원본 URL 그대로 쓰면 클릭은 있어도 어디서 왔는지 알 수 없습니다.

광고비 쓸 때도, 영상 개선할 때도 데이터가 없으면 그냥 감으로 가는 겁니다.

정리

Bitly로 단축 + 이름 뒤에 번호 붙이기. 번호판 없는 차 몰지 마세요.

개념 3 — 설명란 첫 줄 공식

설명

설명란 첫 줄은 딱 이 공식 하나만 씁니다.

👉 [행동 동사] + [구체 결과] + [링크]

예시

"지금 바로 받기 → 메일 30통 줄이는 GPT 템플릿 bit.ly/gptmail01"

"오늘만 할인 → 1인 사업 견적서 양식 5종 bit.ly/estimate01"

행동 동사가 앞에 오면 손가락이 먼저 움직입니다.

반례

"안녕하세요! 오늘은 AI 콘텐츠에 대해 알아보겠습니다. 많은 구독과 좋아요 부탁드려요."

이렇게 쓰면 링크는 더보기 안에 묻힙니다. 스마트폰 유저 80%는 더보기 안 누릅니다.

정리

첫 줄 공식 = 👉 행동 동사 + 구체 결과 + 링크. 인사말은 두 번째 줄부터입니다.

EXERCISE (3–4분)

영상 잠깐 멈추고 직접 써보세요. 5분이면 됩니다.

1단계 — 내 상품 링크 단축하기

Bitly(bitly.com) 접속 → 무료 가입 → 내 상품 URL 붙여넣기 → 링크 이름 뒤에 숫자 붙이기 (예: bit.ly/내상품11). 저장하면 클릭 대시보드 자동 생성됩니다.

2단계 — 설명란 첫 줄 초안 쓰기

빈 문서 열고 딱 한 줄만 씁니다. 👉 [행동 동사] + [내 상품이 주는 구체 결과] + [단축 링크]. 예: "지금 다운받기 → 보고서 작성 시간 1시간 → 5분으로 줄이는 템플릿 bit.ly/report11"

3단계 — 삼각편대 체크

방금 쓴 첫 줄을 설명란에 붙여넣기. 그 다음, 영상 편집 툴에서 마지막 3초 자막에 같은 링크 추가. 마지막으로 영상 올린 뒤 같은 링크를 고정 댓글로 달기. 3곳 다 채웠으면 완료입니다.

4단계 — 클릭 확인

24시간 뒤 Bitly 대시보드 열어보세요. 숫자가 0이면 첫 줄 문구를 바꿔봅니다. 클릭이 들어왔으면 어떤 위치에서 왔는지 확인합니다.

CTA (30초)

다음 12차시에서는 그 클릭이 실제 구매로 이어지게 하는 상품 페이지 문구 작성법을 다룹니다.

클릭까지는 됐는데 거기서 이탈하면 아깝잖아요.

지금 만든 설명란 첫 줄 댓글에 올려주세요. 직접 보고 피드백 드립니다.

예상 분량: 14분 30초
