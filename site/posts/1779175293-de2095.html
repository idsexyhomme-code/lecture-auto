#6 클릭 당기는 썸네일 만든다lecture_script

코스: test-1tier-upgrade-1779174833 · 에이전트: producer

HOOK (45초)

유튜브 영상 올렸는데 조회수가 안 나오죠.

내용은 좋은데 썸네일이 문제입니다.

사람들은 썸네일을 0.3초 보고 클릭할지 말지 결정합니다.

0.3초입니다.

제가 썸네일 하나 바꿨더니 클릭률이 3배 올랐습니다.

오늘 이 영상 끝나면 그 썸네일 바로 만듭니다.

PROMISE (30초)

이번 차시가 끝나면 Canva에서 텍스트 7자, 얼굴 사진, 배경색 대비를 갖춘 썸네일 1장을 직접 만들 수 있습니다.

CORE (8–10분)

개념 1 — 썸네일 텍스트 7자 법칙

설명

스마트폰 화면에서 썸네일 크기는 우표 2장입니다.

그 안에 글자 15자 넣으면 아무도 못 읽습니다.

7자 이내로 자릅니다.

페그 이미지: 손가락 7개를 펼친 손.

글자 세다가 8번째 손가락 구부러지면 잘라내는 겁니다.

예시

"Canva로 썸네일 만드는 방법 총정리" → 14자. 탈락.

"썸네일 3분 완성" → 7자. 통과.

"돈 버는 썸네일" → 7자. 통과.

반례

"SEO 최적화 블로그 글쓰기 비법 대공개" → 16자. 모바일에서 글자가 겹쳐 보입니다.

이런 썸네일은 클릭이 아니라 스크롤을 부릅니다.

정리

썸네일 글자 셉니다. 8자 넘으면 바로 뺍니다.

개념 2 — 얼굴 클로즈업 효과

설명

사람 뇌는 얼굴을 먼저 봅니다.

특히 눈과 눈썹 부위에 0.1초 안에 시선이 꽂힙니다.

페그 이미지: 군중 속에서 눈이 마주친 한 사람.

그게 바로 얼굴 클로즈업의 작동 방식입니다.

예시

썸네일에 전신 사진을 넣으면 얼굴이 손톱만 해집니다.

같은 사진을 어깨 위로 잘라 넣으면 눈빛이 살아납니다.

유튜브 상위 노출 채널 썸네일 10개 중 7개가 얼굴 클로즈업입니다.

제 경험상 얼굴을 크게 넣은 영상이 그렇지 않은 영상보다 클릭률이 높았습니다.

반례

풍경 사진만 쓴 썸네일, 제품 사진만 쓴 썸네일.

정보는 담겼는데 시선을 끌지 못합니다.

1인 사업 채널이라면 얼굴이 브랜드입니다.

숨기면 손해입니다.

정리

사진은 어깨 위로 자릅니다. 눈이 보여야 클릭됩니다.

개념 3 — 배경색 대비 원칙

설명

배경색과 텍스트 색이 비슷하면 둘 다 죽습니다.

대비 공식은 하나입니다.

어두운 배경 + 밝은 글씨. 혹은 밝은 배경 + 어두운 글씨.

페그 이미지: 칠판에 흰 분필. 이것만 기억합니다.

예시

짙은 남색 배경 + 노란 텍스트 → 대비 강함. 클릭됩니다.

흰 배경 + 검정 텍스트 + 빨간 포인트 한 단어 → 깔끔하고 강합니다.

반례

하늘색 배경 + 흰 텍스트 → 대비 약함. 흐릿해 보입니다.

파스텔 톤끼리 조합하면 예뻐 보여도 썸네일로는 약합니다.

예쁜 것과 클릭되는 것은 다릅니다.

정리

Canva 색상 고를 때 배경 먼저 정합니다.

그 다음 반대쪽 명도로 글자색 씁니다.

EXERCISE (3–4분)

지금 영상 일시정지하고 따라 합니다.

1단계 — Canva 열기 (30초)

Canva 접속 → 새 디자인 → YouTube 썸네일 클릭합니다.

1280×720 사이즈가 자동으로 잡힙니다.

2단계 — 배경색 정하기 (30초)

배경 클릭 → 색상 탭 → 짙은 남색(#1A237E) 혹은 검정(#212121) 고릅니다.

지금 단계에서는 어두운 색 하나로 통일합니다.

3단계 — 얼굴 사진 올리기 (1분)

업로드 탭 → 본인 사진 올립니다.

사진을 캔버스 오른쪽에 배치합니다.

사진 꼭짓점 드래그해서 어깨 위가 화면 절반 이상 차도록 키웁니다.

4단계 — 텍스트 7자 넣기 (1분)

텍스트 탭 → 큰 제목 추가 클릭합니다.

7자 이내 문구를 씁니다.

예: "썸네일 3분 완성", "클릭 두 배 내는 법", "조회수 안 나오는 이유"

글자색을 노란색(#FFD600) 또는 흰색(#FFFFFF)으로 바꿉니다.

텍스트를 왼쪽 상단 혹은 중앙에 배치합니다.

5단계 — 저장 (30초)

우측 상단 공유 → 다운로드 → PNG 클릭합니다.

파일이 저장되면 완성입니다.

만든 썸네일 댓글에 올려봅니다.

CTA (30초)

다음 차시에서는 이 썸네일에 어울리는 제목을 씁니다.

클릭되는 제목 공식 딱 3가지만 씁니다.

오늘 만든 썸네일 댓글에 올려주세요.

다른 분들 것 보면서 배우는 게 생각보다 빠릅니다.

예상 분량: 14분 30초
