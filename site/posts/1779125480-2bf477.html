#15 최종 영상 포트폴리오 완성lecture_script

코스: test-1tier-upgrade-1779124486 · 에이전트: producer

HOOK (45초)

4주 동안 콘텐츠 만들었죠. 폴더 안에 파일이 쌓여 있어요. 근데 누구한테 보여준 적은 있나요?

클라이언트가 "포트폴리오 보내줘요" 했을 때, "잠깐만요, 링크 찾아볼게요" 하면서 카카오톡 검색하고 있다면, 오늘이 그걸 끝내는 날입니다.

60초짜리 영상 하나. 그게 지금까지 만든 것들을 대신 말해줍니다.

PROMISE (30초)

이 차시가 끝나면, 4주 작업물 중 대표작 3개를 골라 60초 소개 영상 1편을 직접 만들 수 있습니다. 유튜브나 링크드인에 바로 올릴 수 있는 mp4 파일로요.

CORE (8–10분)

개념 1. 포트폴리오 영상의 뼈대 — '문제 → 과정 → 결과' 3막 구조

설명

60초짜리 영상이라도 뼈대가 없으면 그냥 슬라이드쇼입니다. 보는 사람 머릿속에 남는 게 없어요. 제 경험상 클라이언트가 기억하는 건 딱 하나입니다. "이 사람이 뭘 해결해줬나."

그래서 뼈대는 딱 3막입니다.

  • 1막 (0–15초): 문제. 의뢰인이 갖고 있던 상황.
  • 2막 (15–45초): 과정. 내가 뭘 만들었나, 화면으로 보여줌.
  • 3막 (45–60초): 결과. 숫자 혹은 반응.

예시

"뷰티 쇼핑몰 대표가 상세페이지 글을 매번 외주 맡겼다. 비용은 건당 15만 원, 납기는 4일. 제가 AI 초안 + 직접 수정으로 하루 만에 납품했고, 비용은 3만 원이었다."

이게 1막, 2막, 3막입니다. 15초씩만 써도 60초가 딱 맞아요.

반례

"저는 콘텐츠 기획과 카피라이팅을 합니다." 이런 식으로 시작하는 영상 많이 봤죠? 이건 소개가 아니라 직책 설명입니다. 보는 사람 3초 만에 스크롤 내립니다.

정리 — 메모리 페그

숫자로 외우세요. 15 · 30 · 15. 문제 15초, 과정 30초, 결과 15초. 이 비율만 지키면 60초 뼈대는 완성입니다.

개념 2. 하이라이트 컷 선정 기준 — '3초 안에 뭔지 보이는 것'만 고른다

설명

4주치 작업물에서 뭘 보여줄지 고르는 게 대부분의 경우 제일 오래 걸립니다. 이유는 기준이 없어서예요. 기준 하나만 잡으면 5분 안에 고를 수 있습니다.

기준은 이겁니다. "3초 안에 뭔지 알 수 있나?"

화면을 켰을 때 3초 안에 "아, 이게 상세페이지구나" / "이게 뉴스레터구나" / "이게 인스타 카드뉴스구나" 이게 바로 보여야 합니다.

예시

잘 되는 컷: 인스타그램 피드 화면, 뉴스레터 제목이 큼지막한 화면, 상세페이지 첫 화면. 이건 3초 안에 뭔지 보입니다.

반례

노션 페이지 전체를 천천히 스크롤하는 영상. 구글 독스 초안 화면. 이건 3초 안에 뭔지 안 보입니다. 보는 사람이 "이게 뭐지?" 하는 순간 이미 집중력 끊겼어요.

정리 — 메모리 페그

이미지로 기억하세요. 편의점 냉장고 유리문. 유리 너머로 상품이 뭔지 바로 보여야 손 뻗죠. 안에 뭐가 들었는지 열어봐야 아는 컷은 빼세요.

개념 3. 유튜브·링크드인 업로드 세팅 — 올리는 방식이 결과를 바꾼다

설명

영상을 만들었으면 올려야 합니다. 올리는 곳마다 세팅이 다릅니다. 틀리게 올리면 아무도 안 봐요.

유튜브 — 비공개 아닌 '일부 공개(링크 있는 사람만)' 설정. 클라이언트에게 링크 하나만 건네면 됩니다. 제목은 "OOO 분야 포트폴리오 영상 | [내 이름]" 형식으로.

링크드인 — 피드에 직접 업로드. 유튜브 링크 붙여넣기 하면 알고리즘이 외부 링크라 범위를 줄입니다. mp4 파일 직접 올려야 더 많이 노출됩니다. 자막 파일(srt)도 같이 올리면 무음 재생하는 사람들이 끝까지 봅니다.

예시

링크드인에 mp4 직접 올리고 "4주 동안 만든 뷰티·식품·서비스업 상세페이지 12건입니다. 작업 문의는 DM으로 주세요." 딱 두 줄만 씁니다. 제 경험상 문의 오는 건 이게 더 빨라요.

반례

"안녕하세요, 저는 OO 분야에서 활동 중인 누구입니다. 이번에 포트폴리오를 완성하게 되어 공유합니다. 많은 관심 부탁드립니다." 이렇게 쓰면 링크드인 알고리즘도, 보는 사람도 그냥 지나칩니다.

정리 — 메모리 페그

숫자 2·2·2. 유튜브는 공개 범위 2분 안에 세팅. 링크드인은 mp4 직접 올리고 본문 2줄. 자막 파일 추가 2분. 세팅에 6분 넘게 쓰면 뭔가 잘못된 겁니다.

EXERCISE (3–4분)

영상 일시정지하고 따라오세요. 종이나 노션 페이지 하나 열어두세요.

1단계 — 대표작 3개 고르기 (2분)

4주치 작업물 폴더 엽니다. 각 파일을 열었을 때 3초 안에 뭔지 보이는 것만 체크합니다. 체크된 것 중에서 분야가 다른 것 3개 고릅니다. 같은 분야 3개보다 다른 분야 3개가 더 넓어 보입니다.

2단계 — 60초 뼈대 짜기 (1분)

고른 3개를 보면서 아래 칸을 채우세요.

  • 문제 (15초): 의뢰인 상황 한 줄.
  • 과정 (30초): 보여줄 컷 3개 파일명.
  • 결과 (15초): 숫자 또는 피드백 한 줄.

3단계 — 편집 툴 열기 (1분)

캡컷(무료) 또는 클로바더빙 + 캡컷 조합 씁니다. 새 프로젝트 → 비율 16:9 → 60초 타임라인 생성. 1막 컷 넣고, 2막 컷 넣고, 3막 컷 넣습니다. 자막은 캡컷 자동 자막 기능으로 뽑아냅니다.

여기까지 하면 초안 완성입니다. export는 mp4, 해상도 1080p로 뽑습니다.

CTA (30초)

다음 차시는 이 포트폴리오 영상을 들고 실제 클라이언트한테 제안 메일 보내는 겁니다. 제목부터 본문, 링크 첨부 위치까지 씁니다.

오늘 만든 영상 링크, 댓글에 올려주세요. 제가 직접 보고 한 줄 피드백 남깁니다.

예상 분량: 15분
