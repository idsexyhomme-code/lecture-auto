#3 30분 캡션 생산 루틴, 영상으로 증명하기lecture_script

코스: claude-instagram-caption-pack · 에이전트: producer

HOOK (45초)

매주 인스타 올려야 한다는 건 알아요.

근데 막상 앉으면 30분이 그냥 날아가죠.

캡션 하나 못 쓰고요.

오늘 이 영상은 제가 직접 타이머 켜고 30분 안에 캡션 7개 채우는 걸 화면 녹화로 보여드립니다.

"어떻게 하는 거예요?"가 아니라, 실제로 되는지 눈으로 확인하세요.

PROMISE (30초)

이 차시가 끝나면 다음 주 캡션 7개를, 타이머 30분 안에 직접 채운 화면 녹화 영상 1편을 손에 들고 있게 됩니다.

CORE (8–10분)

개념 1 — 타이머를 세 덩어리로 쪼갠다

설명

30분을 통째로 켜면 뭘 해야 할지 막막합니다.

그래서 저는 세 구간으로 나눕니다.

주제 정리 5분, 초안 15분, 퇴고 10분.

예시

월요일 오전, 타이머 5분 켭니다.

이번 주 올릴 주제 7개를 줄글 없이 키워드만 씁니다.

예: "신제품 입고 / 후기 공유 / 비하인드 / 할인 마감 / Q&A / 팁 / 리마인드"

7개 채우면 타이머 끕니다.

다음 15분, 각 주제에 캡션 초안 2~3줄씩 채웁니다.

잘 쓰려고 하면 안 됩니다. 그냥 말하듯 씁니다.

마지막 10분, 처음부터 읽으면서 어색한 문장만 고칩니다.

전부 다시 쓰는 게 아닙니다. 이상한 부분만 건드립니다.

반례

"주제 정리에 10분 쓰고 시작하면 안 되나요?"

안 됩니다. 주제 고르는 데 시간을 쓰면 초안 쓸 시간이 줄어듭니다.

5분 안에 키워드만 뽑는 이유가 여기 있습니다.

정리 — 메모리 페그

5·15·10. 신호등 세 칸.

빨간불(멈추고 주제 정리) → 노란불(초안 달리기) → 초록불(퇴고 출발).

개념 2 — 막히는 날 쓰는 비상용 문장 뱅크

설명

주제는 잡혔는데 첫 문장이 안 나오는 날이 있습니다.

그날을 위해 문장 뱅크를 미리 만들어 둡니다.

문장 뱅크는 그냥 메모 파일 하나입니다.

자주 쓰는 캡션 오프닝 패턴 10개만 넣어 두면 됩니다.

예시

실제로 제가 쓰는 패턴 3개를 보여드리겠습니다.

첫째, 숫자로 시작하기. "3가지만 바꿨더니 DM이 늘었어요."

둘째, 질문으로 시작하기. "이거 한 번이라도 겪어봤죠?"

셋째, 날짜·요일로 시작하기. "오늘 입고 완료됐습니다."

이 세 패턴만 있어도 첫 문장 막히는 날 바로 꺼내 씁니다.

반례

"패턴 쓰면 캡션이 다 비슷해지지 않나요?"

첫 문장만 패턴입니다. 내용은 그날 주제에 맞게 바뀝니다.

오프닝 패턴과 내용 복붙은 다릅니다.

정리 — 메모리 페그

문장 뱅크 = 자판기.

동전 하나(패턴 선택) 넣으면 캡션 첫 줄이 바로 나옵니다.

개념 3 — 퇴고 끝나면 예약 발행까지 한 번에 끝낸다

설명

캡션 다 썼는데 발행을 미루면 다음 날 다시 열어보게 됩니다.

그러면 또 고칩니다. 30분이 60분이 됩니다.

퇴고 10분이 끝나는 그 자리에서 예약 발행까지 잡습니다.

예시

저는 메타 비즈니스 스위트를 씁니다.

캡션 붙여넣기 → 이미지 업로드 → 날짜·시간 지정 → 예약 버튼.

캡션 1개당 2분 안에 끝납니다.

7개면 14분. 30분 루틴 바로 뒤에 붙여도 부담 없습니다.

반례

"나중에 몰아서 등록하면 안 되나요?"

됩니다. 근데 제 경험상 '나중에'는 잘 안 됩니다.

캡션 파일 열었을 때, 발행 탭도 같이 열려 있는 게 낫습니다.

정리 — 메모리 페그

30분 루틴 + 14분 등록 = 44분 1주일 치 마감.

44분짜리 회의 한 번 대신에, 다음 주 인스타가 채워집니다.

EXERCISE (3–4분)

지금 바로 영상 일시정지하세요.

준비물은 세 가지입니다.

캡션 시트(지난 차시에서 만든 것), 타이머 앱, 화면 녹화 앱.

1단계 — 화면 녹화 시작 (30초)

지금 화면 녹화를 켭니다.

타이머 30분도 같이 켭니다.

2단계 — 주제 정리 5분

캡션 시트 열고, 다음 주 올릴 주제 키워드 7개를 칸에 채웁니다.

설명 없이 단어만 씁니다.

5분 타이머 울리면 멈춥니다. 덜 채워도 넘어갑니다.

3단계 — 초안 15분

각 주제 칸에 캡션 2~3줄씩 씁니다.

잘 쓰려 하지 않습니다. 말하듯 씁니다.

막히면 문장 뱅크에서 오프닝 패턴 하나 가져다 씁니다.

4단계 — 퇴고 10분

처음부터 읽으며 어색한 문장만 고칩니다.

전부 다 바꾸는 게 아닙니다.

5단계 — 화면 녹화 저장

타이머 30분 울리면 녹화를 끝냅니다.

파일 저장 후 5분 내외로 잘라두세요.

이게 이번 차시 실습 결과물입니다.

CTA (30초)

다음 차시에서는 이 캡션 7개를 실제로 올렸을 때 반응이 어떻게 달라지는지, 저장·공유 데이터 읽는 법을 같이 봅니다.

오늘 화면 녹화 영상 찍었으면, 댓글에 "완료"라고 남겨 주세요.

다음 영상 바로 이어서 보시면 됩니다.

예상 분량: 15분
