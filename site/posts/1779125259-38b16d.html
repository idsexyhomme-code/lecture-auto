#11 PDF 전자책 하루 만에 완성lecture_script

코스: test-1tier-upgrade-1779124486 · 에이전트: producer

HOOK (45초)

월요일 오전, 메모장에 아이디어 써놓고 6개월째 그대로인 파일 있죠?

"언젠가 전자책 하나 만들어볼까" 했는데 막상 시작하면 목차부터 막히고, 본문은 언제 쓰고, 디자인은 또 언제 배우나 싶어서 그냥 닫아버린 거요.

오늘은 그 파일 열고 하루 안에 끝냅니다.

AI로 본문 20페이지 뽑고, Canva에서 표지 붙여서 팔 수 있는 PDF 파일 한 개 완성합니다.

PROMISE (30초)

이 영상 끝나면, 표지 포함 20페이지짜리 PDF 전자책 파일 한 개를 직접 손에 쥡니다.

CORE (8–10분)

개념 1 — 챕터별 프롬프트 분할법

설명

AI한테 "전자책 써줘"라고 하면 안 됩니다.

한 번에 다 맡기면 내용이 얕고, 중간에 끊기고, 앞뒤가 안 맞아요.

대신 챕터 하나당 프롬프트 한 개씩 씁니다.

이걸 저는 '도시락 분할법' 이라고 부릅니다.

큰 도시락 통 하나에 밥·반찬 다 부으면 엉망이 되죠.

칸 나눠서 따로따로 담아야 깔끔합니다.

예시

전자책 주제가 "인스타그램으로 고객 모으기"라고 해봅시다.

챕터가 5개면 프롬프트도 5개 씁니다.

1번 챕터 프롬프트: "인스타그램 프로필 세팅법을 초보자 기준으로 A4 3페이지 분량으로 써줘. 소제목 3개 포함, 예시 2개 이상 넣어줘."

이렇게 챕터별로 분리해서 뽑으면 각 챕터가 A4 3~4페이지씩 채워집니다.

5챕터 × 4페이지 = 20페이지, 그냥 나옵니다.

반례

"전자책 20페이지 분량으로 인스타그램 마케팅 완벽 정리해줘."

이렇게 던지면 AI가 목차만 주거나, 각 항목을 두 줄씩만 써버립니다.

분량이 지켜지지 않아요.

정리

챕터 = 도시락 칸. 칸별로 따로 시켜야 꽉 찹니다.

개념 2 — Canva PDF 레이아웃 선택

설명

Canva에서 전자책 만들 때 헷갈리는 포인트가 하나 있습니다.

"어떤 템플릿으로 시작하냐"예요.

잘못 고르면 텍스트가 잘리거나, 인쇄용과 화면용이 섞여서 납품 불가 파일이 됩니다.

Canva 검색창에 "Book" 이라고 치면 됩니다.

거기서 나오는 템플릿 중 "A4" 비율짜리를 고릅니다.

A4는 210×297mm, 화면과 인쇄 둘 다 통합니다.

이걸 저는 '만능 도화지' 라고 기억합니다.

예시

Canva 홈 → 검색창 "Book" 입력 → A4 템플릿 선택 → 표지 1페이지 + 본문 페이지 복제.

본문 페이지는 텍스트 박스 두 개짜리 레이아웃이 가장 깔끔합니다.

제목 박스 하나, 본문 박스 하나.

AI가 뽑아준 텍스트를 그대로 붙여넣으면 됩니다.

완성 후 내보내기 → PDF 표준 선택 → 다운로드.

반례

"프레젠테이션" 템플릿으로 만들면 16:9 비율이 됩니다.

PDF로 내보내도 A4 출력 시 위아래가 잘립니다.

스마트스토어·크몽에 올리면 구매자 불만으로 돌아옵니다.

정리

Canva에서 Book → A4. 이 두 단어만 기억합니다.

개념 3 — 저작권 안전한 이미지 삽입

설명

전자책에 이미지 하나 잘못 넣으면 나중에 삭제 요청 들어옵니다.

구글 이미지 검색해서 붙여넣는 건 지금 당장 멈춥니다.

안전한 이미지 출처는 딱 세 곳입니다.

세 곳 = 3-2-1로 기억합니다.

  • 3 — Canva 내부 이미지 (유료 플랜은 상업용 허가 포함)
  • 2 — Unsplash, Pixabay (무료 상업용 라이선스)
  • 1 — 직접 찍은 사진 (제일 안전)

예시

Canva 무료 플랜 쓴다면, 이미지 검색창에 "free" 필터 켜고 고릅니다.

Unsplash는 unsplash.com에서 키워드 검색 후 다운로드, 별도 크레딧 표기 없이 상업용 쓸 수 있습니다.

반례

Pinterest, 네이버 이미지, 인스타그램 캡처는 전부 안 됩니다.

"출처 표기하면 괜찮겠지" 생각하는 분 있는데, 출처 표기는 저작권 면제가 아닙니다.

판매 파일에 넣으면 침해입니다.

정리

이미지 넣을 때 3-2-1. Canva 내부 → Unsplash·Pixabay → 직접 촬영.

EXERCISE (3–4분)

영상 여기서 일시정지하고 직접 만들어보세요.

Step 1 — 챕터 목록 5개 만들기 (5분)

지금 바로 전자책 주제 하나 정합니다.

내가 아는 것, 매번 누군가한테 설명하는 것이면 됩니다.

그 주제로 챕터 5개를 메모장에 씁니다.

Step 2 — 챕터별 프롬프트 입력 (15분)

ChatGPT나 Claude 열고, 챕터 1번부터 프롬프트 하나씩 넣습니다.

프롬프트 형식: "챕터 제목: [직접 입력]. 독자는 [타깃 설정]. A4 3페이지 분량, 소제목 3개, 실제 예시 2개 이상 포함해서 써줘."

5챕터 다 뽑으면 본문 완성입니다.

Step 3 — Canva에서 파일 세팅 (10분)

Canva 열고 Book → A4 템플릿 선택.

표지 1페이지 만들고, 본문 페이지 19개 추가합니다.

챕터별로 AI 텍스트 붙여넣고, 3-2-1 이미지 규칙으로 사진 넣습니다.

Step 4 — PDF 내보내기 (1분)

오른쪽 위 "공유" → "다운로드" → PDF 표준 선택 → 다운로드.

파일명은 "전자책제목_판매용.pdf"로 저장합니다.

이걸 손에 쥐면 오늘 목표는 끝입니다.

CTA (30초)

다음 차시에서는 이 PDF 파일을 크몽에 올려서 첫 판매를 내는 법을 봅니다.

상품 페이지 제목 쓰는 법, 가격 설정, 썸네일 이미지까지 한 번에 정리합니다.

오늘 만든 전자책 파일 완성하셨으면, 댓글에 주제 하나만 남겨주세요.

직접 봐드립니다.

예상 분량: 15분
