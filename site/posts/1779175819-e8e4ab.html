#15 월 500 숫자를 거꾸로 계산한다lecture_script

코스: test-1tier-upgrade-1779174833 · 에이전트: producer

HOOK (45초)

월 500만 원. 숫자는 정했는데, 다음 날 아침에 뭘 해야 할지 모르겠죠.

블로그 열심히 쓰고, 유튜브 올리고, 인스타도 했는데 통장은 그대로입니다.

문제는 콘텐츠 양이 아닙니다.

숫자를 거꾸로 풀어본 적이 없어서 그렇습니다.

오늘은 500만 원이라는 숫자를 쪼개서, 내일 당장 얼마짜리 상품을 몇 개 팔아야 하는지까지 딱 끊어 드립니다.

PROMISE (30초)

이 차시가 끝나면, 상품가·전환율·조회수 세 칸짜리 표 하나로 내 월 수익 목표를 직접 역산할 수 있습니다.

CORE (8–10분)

개념 1. 전환율 1% 계산법 — "100명 중 1명"

설명

온라인에서 콘텐츠를 보고 실제로 결제하는 비율, 이걸 전환율이라고 부릅니다.

제 경험상, 초반 1인 사업자 기준으로 전환율 1%가 현실적인 출발점입니다.

100명이 내 판매 페이지를 봤으면 1명이 삽니다.

예시

월 방문자 1,000명, 전환율 1% → 10건 판매.

상품가 5만 원이면 50만 원.

상품가 50만 원이면 500만 원.

반례

"나는 팔로워 5,000명인데 왜 한 건도 안 팔리지?"

팔로워 숫자 ≠ 판매 페이지 유입 숫자입니다.

팔로워가 판매 페이지까지 들어온 사람이 50명이라면, 1% 전환 시 0.5명입니다. 안 팔리는 게 당연합니다.

정리

메모리 페그: 1% = 100명 중 1명 = 동전 하나.

이 숫자 하나만 기억하면 뒤 계산이 전부 풀립니다.

개념 2. 상품가별 필요 판매 건수 — "3칸 표"

설명

500만 원을 만들기 위해 필요한 판매 건수는 상품가에 따라 완전히 달라집니다.

직접 보겠습니다.

상품가 필요 판매 건수 필요 판매 페이지 방문자 (전환율 1%)
5만 원 100건 10,000명
50만 원 10건 1,000명
500만 원 1건 100명

예시

5만 원짜리 전자책을 파는 사람이 있습니다.

월 500만 원을 벌려면 매달 100권을 팔아야 합니다.

판매 페이지에 매달 10,000명을 끌어와야 한다는 뜻입니다.

반면 50만 원짜리 온라인 강의는 10명만 팔면 됩니다.

방문자 1,000명이면 충분합니다.

반례

"그럼 무조건 비싼 상품을 팔면 되지 않나요?"

비싼 상품은 신뢰가 먼저 쌓여야 팔립니다.

콘텐츠 6개월 미만이라면 5만 원짜리로 신뢰를 증명하고, 그다음에 올리는 순서가 현실적입니다.

정리

메모리 페그: 상품가에 0을 두 개 떼면 필요 방문자가 나온다.

5만 원 → 10,000명, 50만 원 → 1,000명. 0 두 개만 떼면 됩니다.

개념 3. 조회수 목표 설정 — "깔때기 3층"

설명

조회수가 전부 판매 페이지 방문으로 연결되지는 않습니다.

콘텐츠 조회 → 링크 클릭 → 판매 페이지 방문 → 결제, 이렇게 3번 걸러집니다.

각 단계마다 대략 10분의 1로 줄어든다고 보면 됩니다.

예시

판매 페이지 방문자 1,000명이 필요하다고 합시다.

링크 클릭률 10% → 링크 노출 10,000회 필요.

콘텐츠 클릭률 10% → 콘텐츠 조회수 100,000회 필요.

50만 원짜리 강의 하나로 월 500만 원을 벌려면, 월 조회수 10만 회가 기준점이 됩니다.

반례

"나는 조회수 30만인데 왜 매출이 없지?"

링크를 콘텐츠 안에 안 넣었거나, 판매 페이지가 없거나, 상품 자체가 없는 경우입니다.

깔때기가 끊겨 있으면 조회수는 구경꾼 숫자일 뿐입니다.

정리

메모리 페그: 깔때기 3층 — 조회수·클릭·결제, 각 층마다 10분의 1.

조회수에서 결과물까지 0이 두 개 빠집니다.

EXERCISE (3–4분)

지금 영상을 일시정지하세요.

종이 한 장, 또는 스프레드시트 빈 파일을 엽니다.

아래 순서대로 채웁니다.

1단계 — 목표 수입 적기

A1셀에 월 목표 수입을 씁니다. 일단 500만 원으로 시작합니다.

2단계 — 상품가 3가지 써보기

B열에 5만 원, 50만 원, 150만 원 세 줄을 씁니다.

3단계 — 필요 판매 건수 계산

C열에 A1 ÷ B열을 넣습니다.

5만 원이면 100건, 50만 원이면 10건, 150만 원이면 약 34건이 나옵니다.

4단계 — 필요 판매 페이지 방문자 계산

D열에 C열 × 100을 씁니다. (전환율 1% 기준)

5단계 — 필요 콘텐츠 조회수 계산

E열에 D열 × 100을 씁니다. (클릭률 1% 기준)

표가 완성되면 세 줄을 눈으로 비교해 보세요.

지금 내가 만들 수 있는 상품가, 지금 내 채널 조회수와 가장 가까운 줄이 어디인지 체크합니다.

그 줄이 지금 내 현실 출발점입니다.

CTA (30초)

다음 차시 #16에서는 이 표의 조회수를 실제로 채우는 콘텐츠 발행 주기를 잡습니다.

일주일에 몇 편을, 어떤 주제로 올려야 이 숫자에 닿는지 구체적으로 봅니다.

오늘 만든 역산표, 댓글에 숫자 하나만 남겨 주세요.

내 상품가가 얼마인지, 딱 그 숫자만요.

예상 분량: 15분
