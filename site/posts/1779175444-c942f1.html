#9 팔 수 있는 PDF 상품 만든다lecture_script

코스: test-1tier-upgrade-1779174833 · 에이전트: producer

HOOK (45초)

월요일 아침, 블로그 글 10개 올렸는데 통장엔 0원.

콘텐츠는 쌓이는데 돈은 안 들어오죠.

문제는 글이 아닙니다.

파는 물건이 없는 겁니다.

오늘은 Notion이나 구글 독스로 PDF 파일 1개 만듭니다.

그게 첫 번째 디지털 상품이 됩니다.

PROMISE (30초)

이 영상이 끝나면, 표지·목차·본문이 들어간 5~10페이지짜리 PDF 파일 1개를 직접 완성합니다.

CORE (8–10분)

개념 1 — PDF 상품, 딱 3가지 유형만 있습니다

설명

PDF 상품은 크게 세 가지입니다.

첫째, 정보형 — 내가 아는 것을 정리한 문서. 둘째, 템플릿형 — 빈 칸 채우면 되는 양식. 셋째, 체크리스트형 — 순서대로 체크하는 목록.

예시

정보형: "인스타 피드 기획하는 법 7가지" 템플릿형: "주간 매출 정리 시트" 체크리스트형: "블로그 글 올리기 전 확인 15항목"

반례

"제 모든 노하우를 담은 200페이지 전자책"은 만들다 지쳐서 포기합니다.

처음엔 5~10페이지로 딱 잘라야 합니다.

정리 — 메모리 페그: 정·템·체 (정보·템플릿·체크리스트)

이 세 글자만 기억하세요.

개념 2 — 가격은 이렇게 정합니다

설명

가격을 못 정해서 출시를 미루는 분이 많습니다.

제 경험상 PDF 가격은 딱 두 가지 기준으로 정합니다.

기준 1 — 시간 절약값: 이 PDF 없이 혼자 찾으면 몇 시간 걸리나? 기준 2 — 행동 유발값: 이걸 보고 바로 뭔가를 할 수 있나?

예시

"인스타 프로필 세팅 체크리스트" — 혼자 찾으면 2~3시간 걸립니다. 시간 절약값이 있고, 바로 세팅할 수 있으니 9,900원은 납득됩니다.

반례

"다이어트 정보 모음" — 검색하면 다 나옵니다. 행동으로 연결이 안 되면 990원도 팔기 어렵습니다.

정리 — 메모리 페그: "2시간 절약 = 9,900원 법칙"

가격 기준이 안 잡히면 이 공식 먼저 대입해 보세요.

개념 3 — 표지·목차·본문, 이 순서로 씁니다

설명

PDF는 딱 3단 구조입니다.

1페이지 — 표지: 제목 + 부제목 + 작성자 이름 2페이지 — 목차: 챕터 번호 + 한 줄 설명 3~10페이지 — 본문: 챕터별로 설명 + 예시 1개씩

예시

표지: "인스타 프로필 세팅 체크리스트 / 팔로워 0명에서 시작하는 계정 만들기 / 홍길동" 목차: "1. 계정 이름 정하는 법 / 2. 소개란 3줄 쓰기 / 3. 첫 9장 피드 기획" 본문: 각 챕터 1~2페이지, 설명 후 나쁜 예·좋은 예 비교

반례

표지 없이 바로 본문으로 시작하면 사는 사람 입장에서 허접해 보입니다.

1페이지짜리 표지가 신뢰도를 올립니다.

정리 — 메모리 페그: "표·목·본 = 1·1·8"

표지 1장, 목차 1장, 본문 8장.

이 숫자로 파일 구조를 잡으세요.

EXERCISE (3–4분)

지금 영상 일시정지하고 직접 만들어 보세요.

Step 1 — 유형 고르기 (1분)

정·템·체 중 하나를 지금 결정합니다.

적지 않으면 안 됩니다. 노트에 딱 한 줄 써 주세요. 예: "나는 체크리스트형 PDF를 만든다."

Step 2 — 표지 만들기 (1분)

Notion 또는 구글 독스 새 문서를 엽니다.

제목: 내 PDF 이름을 씁니다. 부제목: 이 PDF로 뭘 할 수 있는지 한 줄. 이름: 본인 이름 또는 브랜드명.

폰트 크기 제목 36, 부제목 18로 설정합니다.

Step 3 — 목차 만들기 (1분)

챕터를 3~5개 씁니다.

번호 + 챕터 이름 + 한 줄 설명.

예: "3. 소개란 3줄 쓰기 — 처음 보는 사람이 바로 팔로우하게 만드는 문장"

Step 4 — 본문 초안 1챕터 쓰기 (1분)

챕터 1개만 지금 씁니다.

설명 3~5줄, 나쁜 예 1개, 좋은 예 1개.

이게 되면 나머지는 똑같이 복붙해서 채웁니다.

CTA (30초)

다음 차시에서는 이 PDF 파일을 크몽이나 스마트스토어에 실제로 올립니다.

가격 설정부터 상품 설명 페이지 쓰는 법까지 같이 합니다.

오늘 만든 PDF 파일, 댓글에 제목 한 줄만 남겨 주세요.

예상 분량: 15분
