#5 영상 없이 쇼츠 만들기lecture_script

코스: test-1tier-upgrade-1779124486 · 에이전트: producer

HOOK (45초)

월요일 아침, 쇼츠 올릴 영상 없어서 또 멈췄죠.

카메라 앞에 서기 싫고, 목소리 넣기도 부담스럽고.

결국 오늘도 그냥 넘깁니다.

근데 사실 얼굴도 목소리도 없이 쇼츠 올리는 사람들 있습니다.

대본 하나만 있으면 됩니다.

이 영상에서 CapCut이나 Canva로 60초짜리 쇼츠를 바로 만드는 법 보여드립니다.

PROMISE (30초)

이번 차시가 끝나면, 대본 텍스트 하나를 60초 자막 영상 mp4 파일로 저장할 수 있습니다.

CORE (8–10분)

개념 1 — 자막 자동 생성 기능 위치

설명

CapCut 앱 기준입니다.

새 프로젝트 만들고 영상 소스 하나 올리면 하단 메뉴가 뜹니다.

거기서 '텍스트' 탭 누르면 '자동 캡션' 버튼 있습니다.

Canva 기준이면 '프레젠테이션 → 비디오 편집 → 자막 추가' 순서입니다.

예시

30초짜리 대본 텍스트를 CapCut에 붙여 넣으면 자막이 자동으로 문장 단위로 잘립니다.

수동으로 타이밍 맞출 필요 없습니다.

반례

단, 자동 자막은 발음 기반이라 텍스트를 직접 붙여 넣는 게 아닙니다.

음성 파일이 있어야 인식됩니다.

음성 없이 텍스트만 올리려면 'TTS(텍스트 음성 변환)' 기능을 먼저 쓰고 그 음성 파일에 자막을 붙이는 순서로 해야 합니다.

정리 — 메모리 페그: '텍스트 → 소리 → 자막' 3단계

텍스트를 소리로 바꾸고, 그 소리에 자막 붙인다고 기억하세요.

개념 2 — 배경 영상 무료 소스 3곳

설명

영상이 없을 때 쓰는 무료 소스 사이트 3곳입니다.

하나, Pexels (pexels.com/videos)

둘, Pixabay (pixabay.com/videos)

셋, Coverr (coverr.co)

셋 다 상업용 무료고 워터마크 없습니다.

예시

'커피숍', '노트북', '도시 야경' 같은 단어로 검색하면 10초~30초짜리 루프 영상이 바로 나옵니다.

60초 쇼츠라면 같은 영상을 2~3번 반복해도 됩니다.

어차피 자막이 화면 중심이라 배경은 흐릿하게 써도 됩니다.

반례

Unsplash는 사진 위주라 영상이 거의 없습니다.

헷갈려서 거기서 찾다 시간 낭비하는 경우 많습니다.

처음부터 Pexels Videos 탭으로 바로 들어가세요.

정리 — 메모리 페그: 'P·P·C'

Pexels, Pixabay, Coverr. 이니셜 P·P·C로 기억하세요.

개념 3 — 썸네일 텍스트 규칙

설명

썸네일에 텍스트 넣을 때 지키는 규칙 3가지입니다.

첫째, 글자 수 15자 이내.

둘째, 폰트 크기는 화면 세로의 15% 이상.

셋째, 배경 대비 색상 무조건 흰색 또는 노란색.

예시

'AI로 쇼츠 대본 쓰는 법' — 14자, 딱 맞습니다.

배경이 어두운 도시 야경이라면 흰 글씨에 검정 테두리 2px.

Canva에서 텍스트 효과 → 그림자 or 윤곽선으로 바로 됩니다.

반례

'ChatGPT를 이용해서 유튜브 쇼츠 대본을 작성하는 방법' — 이건 30자 넘어서 모바일에서 안 읽힙니다.

썸네일은 3초 안에 읽혀야 합니다.

3초 안에 못 읽히면 그냥 지나갑니다.

정리 — 메모리 페그: '15·15·흰노'

15자, 15%, 흰색 또는 노란색. 숫자 15 두 번에 색 두 개입니다.

EXERCISE (3–4분)

지금 영상 일시정지하고 따라 해보세요.

1단계 — 대본 준비 (1분)

지난 4차시에서 만든 쇼츠 대본 텍스트를 엽니다.

없으면 '30초 안에 읽히는 자막 영상 만드는 법'이라는 주제로 5문장만 씁니다.

2단계 — 배경 영상 다운로드 (1분)

Pexels(pexels.com/videos)에서 '노트북' 또는 '타이핑' 검색합니다.

10초~20초짜리 영상 하나 다운로드합니다.

3단계 — CapCut 또는 Canva에서 편집 (2분)

CapCut이면: 새 프로젝트 → 배경 영상 추가 → 텍스트 탭 → TTS로 대본 읽히기 → 자동 캡션 생성.

Canva이면: 비디오 → 배경 영상 넣기 → 텍스트 추가 → 애니메이션 '페이드' 적용.

4단계 — 썸네일 텍스트 + 저장 (1분)

첫 프레임에 15자 이내 텍스트 넣습니다.

흰색 글씨, 윤곽선 추가합니다.

mp4로 저장합니다.

저장된 파일 이름은 '쇼츠_연습_날짜'로 바꿔두세요.

CTA (30초)

다음 차시에서는 이 영상을 유튜브 쇼츠와 인스타그램 릴스에 올리는 법을 봅니다.

제목 태그 설명란까지, 업로드 화면에서 뭘 써야 하는지 구체적으로 보여드립니다.

댓글에 오늘 만든 영상 주제 한 줄만 남겨주세요.

예상 분량: 15분
