#13 숫자로 뭐가 팔렸는지 본다lecture_script

코스: test-1tier-upgrade-1779174833 · 에이전트: producer

HOOK (45초)

지난 2주 동안 영상 4개 올렸는데, 뭐가 팔렸는지 모릅니다. 댓글은 몇 개 달렸고, 좋아요도 좀 눌렸는데. 그게 돈이랑 연결됐는지는 아무도 말 안 해줬습니다. 유튜브 스튜디오 켜도 숫자만 잔뜩이고, 어디를 봐야 하는지 모릅니다. 오늘 이 영상 끝나면, 그 숫자들 중에 딱 3개만 봅니다. 그리고 어떤 영상이 돈을 벌었는지, 표 하나로 정리됩니다.

PROMISE (30초)

이번 차시가 끝나면, 2주치 영상 데이터를 조회수·클릭률·판매 건수 기준으로 표에 채울 수 있습니다.

CORE (8–10분)

개념 1 — 유튜브 스튜디오에서 볼 숫자는 딱 3개

설명 유튜브 스튜디오에 들어가면 숫자가 30개쯤 됩니다. 시청 지속률, 노출수, 구독자 증감, 평균 시청 시간... 전부 볼 필요 없습니다. 1인 사업자가 봐야 할 건 딱 3개입니다.

  • 노출수: 유튜브가 내 영상을 몇 번 보여줬나
  • 클릭률(CTR): 본 사람 중에 몇 %가 클릭했나
  • 조회수: 실제로 영상을 본 사람 수

예시 노출수 1,000 / 클릭률 4% / 조회수 40. 이 영상은 유튜브가 1,000명한테 썸네일 보여줬고, 그 중 40명이 클릭해서 들어온 겁니다.

반례 조회수 500이라도 노출수가 10,000이면 클릭률 5%. 조회수 500인데 노출수가 5,000이면 클릭률 10%. 두 영상은 조회수는 같아도 썸네일 성과가 두 배 차이 납니다. 조회수만 보면 이 차이를 절대 못 잡습니다.

정리 메모리 페그 — "노출·클릭·조회 = 문·손잡이·입장" 문(노출)이 있어야, 손잡이(클릭)를 잡고, 방에 들어옵니다(조회). 이 순서가 끊기는 지점이 어딘지 보는 겁니다.

개념 2 — 클릭률, 이 숫자가 낮으면 썸네일이 문제

설명 클릭률 기준은 유튜브 공식 데이터 기준으로 이렇게 봅니다.

  • 2% 이하 → 썸네일·제목이 눈에 안 들어옴
  • 2~5% → 평균 수준
  • 5~10% → 썸네일이 잘 당기는 편
  • 10% 초과 → 구독자 충성도가 높거나, 제목이 아주 정확하게 꽂힌 케이스

단, 노출수가 200 이하일 땐 이 기준을 적용하면 안 됩니다. 표본이 너무 적어서 숫자가 튑니다.

예시 영상 A — 노출수 2,000 / 클릭률 1.8% → 썸네일 바꿔야 함. 영상 B — 노출수 1,500 / 클릭률 6.2% → 제목·썸네일 이 조합 다음 영상에 씁니다.

반례 클릭률 12%인데 조회수 6. 노출수가 50밖에 안 됩니다. 이건 지인 3명이 클릭한 거일 수 있습니다. 클릭률은 노출수 500 이상일 때부터 의미가 생깁니다.

정리 메모리 페그 — "클릭률은 낚싯바늘" 물에 던졌을 때(노출) 물고기가 무는 비율(클릭률)입니다. 500마리 이상 있는 연못에서 던져야 바늘이 좋은지 나쁜지 압니다.

개념 3 — 안 팔린 영상 판단 기준

설명 조회수 괜찮은데 판매가 0건인 영상이 있습니다. 이걸 "실패"라고 바로 결론 내리면 틀립니다. 3가지를 순서대로 봅니다.

  1. 조회수 대비 링크 클릭 수 — 영상 설명란 링크를 클릭했는가
  2. 링크 클릭 대비 판매 건수 — 링크 들어갔는데 안 샀는가
  3. 판매 건수 0 + 링크 클릭도 0 — 링크 자체를 안 달았거나, 영상에서 언급을 안 한 것

제 경험상, 판매 0인 영상의 대부분은 세 번째입니다. 영상 안에서 링크 언급을 안 했거나, 설명란에 링크가 없습니다.

예시 조회수 200 / 링크 클릭 0 / 판매 0. 영상 다시 보니까 끝에 "구매 링크는 설명란에 있어요" 한 마디가 없었습니다. 그 한 마디 넣고 다음 영상에서 같은 주제로 다시 올렸더니 조회수 180 / 링크 클릭 22 / 판매 3건 나왔습니다.

반례 링크 클릭 30 / 판매 0이면, 랜딩 페이지 문제입니다. 영상은 잘 됐는데, 들어간 다음에 사기 싫어진 겁니다. 이 경우엔 영상이 아니라 판매 페이지를 손봐야 합니다.

정리 메모리 페그 — "조회수는 손님 수, 클릭은 가게 입장, 판매는 계산대" 손님이 100명인데 가게 문을 못 찾으면 조회수 문제. 가게 들어왔는데 계산 안 하면 판매 페이지 문제. 이 3단계 중 어디가 막혔는지만 찾으면 됩니다.

EXERCISE (3–4분)

지금 영상 일시정지하고 따라 해봅니다.

준비물: 유튜브 스튜디오, 구글 시트 또는 엑셀

Step 1 — 표 틀 만들기 (1분)

구글 시트 열고, 맨 위 행에 이렇게 씁니다.

영상명 업로드일 노출수 클릭률(%) 조회수 링크 클릭 판매 건수

열 7개입니다. 그대로 복사해도 됩니다.

Step 2 — 유튜브 스튜디오에서 데이터 가져오기 (2분)

  1. 유튜브 스튜디오 → 왼쪽 메뉴 '콘텐츠' 클릭
  2. 최근 2주 영상 목록 확인
  3. 영상 하나 클릭 → 상단 '분석' 탭 클릭
  4. '노출수', '클릭률', '조회수' 숫자를 표에 채웁니다
  5. 영상별로 반복

Step 3 — 판매 건수 채우기 (1분)

판매 플랫폼(크몽, 클래스101, 자사몰 등)에서 같은 기간 판매 내역 확인합니다. 영상 업로드일 기준 ±3일 안에 들어온 주문을 해당 영상 행에 씁니다. 정확히 안 맞아도 됩니다. 근사치로 씁니다.

Step 4 — 색 표시 (30초)

클릭률 2% 이하 셀 → 빨간색으로 표시. 판매 건수 0 + 링크 클릭 0 셀 → 노란색으로 표시.

이 표가 지금부터 매주 업데이트할 성과 기록지가 됩니다.

CTA (30초)

다음 차시 #14에서는, 이 표에서 잘 팔린 영상 하나를 골라서 제목·썸네일·설명란을 어떻게 다시 쓰는지 봅니다. 만든 표 구글 시트 캡처해서 댓글에 올려주세요. 클릭률이 제일 낮은 영상 제목도 같이 써주시면, 다음 영상에서 직접 고쳐봅니다.

예상 분량: 15분
