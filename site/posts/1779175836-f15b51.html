#15 월 500 숫자를 거꾸로 계산한다lecture_script

코스: test-1tier-upgrade-1779174833 · 에이전트: producer

HOOK (45초)

월 500만 원 목표 세웠죠.

근데 막상 뭘 얼마나 팔아야 하는지 모르겠는 거잖아요.

블로그 열심히 쓰고, 영상 만들고, SNS도 올리는데 — 숫자가 연결이 안 돼요.

"그냥 조회수 늘리면 되겠지" 하다가 3개월이 그냥 지나가는 거예요.

오늘은 다릅니다.

500만 원이라는 숫자를 거꾸로 분해해서 — 하루에 뭘 몇 개 팔면 되는지까지 쪼갭니다.

PROMISE (30초)

이 영상 끝나면 상품가·전환율·조회수 세 칸짜리 역산표를 직접 채울 수 있습니다.

CORE (8–10분)

핵심 개념 1 — 전환율 1% 계산법

설명

전환율은 내 페이지 들어온 사람 중에서 실제로 산 사람 비율입니다.

업계 평균은 대략 1~3%.

일단 1%로 잡으세요.

100명 들어오면 1명 삽니다.

예시

블로그 판매 페이지 월 조회수 2,000건.

1% 적용하면 판매 20건.

반례

"저는 SNS 팔로워 5,000명인데 왜 안 팔리나요?"

팔로워랑 방문자는 달라요.

5,000명이 게시물 봐도 판매 페이지 클릭은 200명, 실제 구매는 2명이 됩니다.

클릭까지 가는 비율이 따로 있어요.

메모리 페그 — "100명의 법칙"

방문자 100명 = 구매자 1명.

이 숫자를 머릿속에 붙여두세요.

핵심 개념 2 — 상품가별 필요 판매 건수

설명

월 500만 원을 벌려면 상품값에 따라 팔아야 하는 건수가 달라집니다.

딱 세 경우만 보겠습니다.

  • 상품가 5만 원 → 100건 팔아야 해요
  • 상품가 15만 원 → 34건이면 됩니다
  • 상품가 50만 원 → 10건입니다

예시

전자책 5만 원짜리를 팔면 월 100건.

전환율 1% 적용 — 판매 페이지 방문자 10,000명이 필요해요.

반면 코칭 프로그램 50만 원짜리는 10건만 팔면 됩니다.

판매 페이지 방문자 1,000명이면 충분해요.

반례

"그럼 비싼 거 팔면 무조건 유리하잖아요?"

50만 원짜리는 고객이 구매 결정에 훨씬 오래 걸립니다.

전환율이 1%보다 낮게 나오는 경우가 많아요.

제 경험상 50만 원 이상 상품은 전환율 0.3~0.5%로 보수적으로 잡는 게 낫습니다.

메모리 페그 — "5·15·50 사다리"

5만, 15만, 50만 — 세 계단.

올라갈수록 건수는 줄고, 설득 시간은 늘어납니다.

핵심 개념 3 — 조회수 목표 설정

설명

판매 페이지 방문자를 만들려면 콘텐츠 조회수가 먼저 있어야 해요.

콘텐츠 → 판매 페이지 클릭률은 대략 5~10%.

보수적으로 5% 씁니다.

판매 페이지 방문자 10,000명이 필요하면 콘텐츠 조회수는 200,000회가 돼야 합니다.

판매 페이지 방문자 1,000명이면 조회수 20,000회.

예시

블로그 포스팅 1개 월 평균 조회수 500건.

20,000회 채우려면 포스팅 40개가 필요합니다.

이미 쌓인 게 20개면 — 20개 더 쓰면 됩니다.

반례

"조회수 200,000은 너무 많아서 엄두가 안 나요."

그래서 상품가를 올리는 겁니다.

50만 원짜리 10건이면 방문자 2,000명 — 조회수는 40,000회만 있으면 돼요.

전자책 팔 때 조회수의 20% 수준입니다.

메모리 페그 — "조회수 → 방문 → 구매, 20:1:0.1"

콘텐츠 조회수 20 → 판매 페이지 1 → 구매 0.1.

숫자 세 개만 기억하세요.

EXERCISE (3–4분)

지금 영상 일시정지하세요.

빈 종이 한 장, 혹은 메모앱 여세요.

1단계 — 상품가 결정

지금 팔고 싶은 상품 하나 적으세요.

상품가를 5만 원 / 15만 원 / 50만 원 중 하나로 고르세요.

2단계 — 필요 판매 건수 계산

500만 원 ÷ 상품가 = 월 필요 판매 건수.

숫자 적으세요.

3단계 — 필요 방문자 수 계산

판매 건수 × 100 = 판매 페이지 월 필요 방문자 수.

(전환율 1% 기준 — 50만 원 이상이면 × 200으로 계산하세요.)

4단계 — 필요 조회수 계산

판매 페이지 필요 방문자 × 20 = 월 필요 콘텐츠 조회수.

5단계 — 표로 한 줄 정리

상품가 월 판매 건수 방문자 월 조회수 목표
직접 입력 직접 입력 직접 입력 직접 입력

이 표 한 장이 앞으로 콘텐츠 만들 때 기준이 됩니다.

다 됐으면 다시 재생하세요.

CTA (30초)

다음 차시 #16에서는 이 조회수 목표를 채울 콘텐츠를 월 몇 개 올려야 하는지 — 날짜까지 쪼갭니다.

오늘 만든 역산표 숫자를 댓글에 올려두세요.

상품가, 목표 조회수 두 숫자만이라도요.

같은 목표 가진 분들이랑 비교해보면 생각보다 도움이 됩니다.
