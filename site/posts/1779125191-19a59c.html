#10 디지털 상품 첫 번째 기획lecture_script

코스: test-1tier-upgrade-1779124486 · 에이전트: producer

HOOK (45초)

오늘 아침에도 블로그 글 썼죠?

조회수 나오고, 댓글도 달리고.

근데 통장엔 아무것도 없습니다.

글 잘 쓰는데 왜 돈이 안 될까 — 이 질문, 저도 2년 동안 했습니다.

답은 간단했습니다.

콘텐츠를 상품으로 묶지 않았기 때문입니다.

오늘 이 영상 한 편으로, 그 글들이 팔리는 PDF 한 권이 됩니다.

PROMISE (30초)

이 차시가 끝나면, 디지털 상품 기획서 1장을 손에 들고 있습니다.

제목, 목차, 가격, 팔 곳까지 — 다 채워진 1장입니다.

오늘 만든 기획서가 크몽 등록의 출발점이 됩니다.

CORE (8–10분)

개념 1 — 팔리는 디지털 상품 3가지 유형

설명

디지털 상품은 크게 세 종류입니다.

① 방법 PDF — "어떻게 하는지" 알려주는 전자책.

② 작업 대신 해주는 템플릿 — 고객이 빈칸만 채우면 됩니다.

③ 모음집(리스트업) — 쓸 만한 것들만 골라 묶은 파일.

예시

  • 방법 PDF: "인스타 팔로워 0명에서 1,000명 만든 글쓰기 법"
  • 템플릿: "견적서 자동 계산 엑셀 + 고객 안내 메일 문구 3종"
  • 모음집: "프리랜서가 쓰는 계약서 문구 50개"

반례

"제 모든 노하우를 담은 500페이지 PDF"는 안 팔립니다.

범위가 넓을수록 사는 사람이 줄어듭니다.

"딱 이 문제 하나"를 푸는 상품이 삽니다.

정리 — 메모리 페그: 🧊 얼음틀

얼음틀을 떠올리세요.

작고 네모난 칸 하나에 물을 딱 맞게 채웁니다.

내 상품도 그렇습니다. 고통 하나, 해결 하나, 파일 하나.

개념 2 — 가격 설정 기준: 시간 대비 가치

설명

가격 고민할 때 쓰는 공식이 하나 있습니다.

"내 상품이 고객의 시간을 몇 시간 아껴주나?"

시간당 고객의 시급을 2만 원으로 잡으면,

3시간 아껴주는 템플릿은 6만 원짜리입니다.

예시

제 경험상, 크몽에서 잘 팔리는 PDF 가격대는 세 구간입니다.

  • 9,900원 ~ 1만 9,000원: 입문용, 30분짜리 고통 해결
  • 2만 9,000원 ~ 4만 9,000원: 실무 즉시 쓰는 템플릿 묶음
  • 6만 9,000원 이상: 특정 직군·업종 전용, 대체재가 없을 때

반례

"열심히 만들었으니까 10만 원"은 안 됩니다.

고객은 제작 시간에 돈 내는 게 아닙니다.

자기 시간을 얼마나 아끼냐에 돈 냅니다.

반대로 너무 싸게 내면 "이게 뭔가 있나?" 싶어서 안 삽니다.

2만 원대 이하는 충동 구매, 3만 원대 이상은 신뢰 구매입니다.

정리 — 메모리 페그: ⏱ 타이머 3개

타이머 3개를 떠올리세요.

10분짜리, 30분짜리, 3시간짜리.

고객 시간 10분 → 1만 원대, 30분 → 3만 원대, 3시간 이상 → 7만 원대.

이 타이머 기준으로 가격을 먼저 잡고, 목차를 맞춥니다.

개념 3 — 크몽·클래스101 상품 페이지 구조

설명

상품을 만들었어도 페이지 구조를 모르면 팔리지 않습니다.

크몽 기준으로, 잘 팔리는 페이지는 딱 4칸으로 됩니다.

① 제목 — ② 이런 분께 딱 맞습니다 — ③ 목차/구성 — ④ 후기 또는 미리보기

예시

제목: "인스타 첫 글 쓰는 사람을 위한 문장 템플릿 20개"

이런 분께: "무슨 말 써야 할지 몰라서 15분째 빈 화면 보고 있는 분"

목차/구성: "1부 자기소개 문장 5개 / 2부 제품 소개 문장 7개 / ..."

미리보기: 실제 템플릿 2개를 그대로 공개.

반례

"저는 10년 경력의 마케터입니다. 이 PDF에는 제 모든 노하우가..."

이런 식의 자기 소개로 시작하는 페이지는 대부분 안 팔립니다.

고객은 내 경력이 궁금한 게 아닙니다.

"이거 사면 내 문제가 해결되나?"만 봅니다.

정리 — 메모리 페그: 🪟 창문 4칸

창문 4칸을 떠올리세요.

제목 / 이런 분 / 구성 / 미리보기.

이 4칸이 채워지면 페이지가 됩니다.

클래스101도 구조는 거의 같습니다. 섬네일이 조금 더 중요할 뿐입니다.

EXERCISE (3–4분)

지금 영상 일시정지하고, 종이 한 장 꺼내세요.

아니면 노션, 메모장도 됩니다.

아래 5칸을 채웁니다.

① 상품 유형 고르기

방법 PDF / 템플릿 / 모음집 중 하나만 동그라미.

② 제목 쓰기

"[대상]을 위한 [결과물] [유형]"으로 씁니다.

예: "부업 초보를 위한 크몽 첫 등록 체크리스트 20개"

③ 목차 3개 이상 쓰기

1부, 2부, 3부 — 각각 한 줄로만.

"뭘 담을지"보다 "고객이 이걸 보고 사고 싶을지"로 씁니다.

④ 가격 결정

타이머 기준 기억나죠?

고객 시간 얼마나 아껴주는 상품인지 먼저 쓰고, 가격 숫자 씁니다.

⑤ 팔 플랫폼 하나 고르기

크몽 / 클래스101 / 내 블로그 스마트스토어 중 하나.

처음엔 하나만 씁니다.

5칸 다 채웠으면 재생 버튼 눌러도 됩니다.

CTA (30초)

다음 차시는 이 기획서를 실제 크몽 페이지에 올리는 법입니다.

제목 쓰는 법, 섬네일 만드는 법, 가격 칸 설정까지 — 화면 공유로 같이 합니다.

오늘 만든 기획서 1장, 댓글에 제목만 딱 한 줄 올려보세요.

피드백 드립니다.
