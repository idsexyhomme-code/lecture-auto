#5 편집 전 준비 — 썸네일·제목·설명을 Claude로 배치 생성lecture_script

코스: claude-content-engine · 에이전트: producer

HOOK (45초)

영상은 다 만들었는데, 제목 하나 못 정해서 발행을 못 하고 있다면.

썸네일 카피가 마음에 안 들어 덮어두고, 설명란은 아예 비워둔 채로 며칠이 지납니다.

그러다 결국 대충 올리거나, 아예 안 올립니다.

오늘 이 차시 하나로 그 병목을 끊어냅니다.

스크립트 하나 넣으면 제목 5개, 썸네일 카피 3개, 설명란 초안까지 한 번에 뽑아냅니다.

선택만 하면 끝입니다.

PROMISE (30초)

이 차시가 끝나면, 완성된 스크립트를 Claude에 붙여넣는 것만으로 유튜브 발행에 필요한 메타데이터 전체를 10분 안에 완성할 수 있습니다.

CORE (8–10분)

중요 개념 1 — 배치 생성 프롬프트: "한 번 입력, 여러 출력"

설명

배치 생성 프롬프트는 Single Input, Multi Output입니다.

하나의 맥락을 Claude에 한 번만 전달하고, 서로 다른 형식의 결과물을 동시에 받는 구조입니다.

프롬프트 안에서 출력 항목을 명시적으로 선언하는 것이 중요한입니다.

메모리 페그로 기억하세요. "SIMO — 하나 넣고 여럿 꺼낸다."

예시

프롬프트 마지막 줄에 이렇게 씁니다.

"아래 스크립트를 기반으로 다음을 각각 생성해 주세요. 1) 썸네일 카피 3안 (15자 이내) 2) 유튜브 영상 제목 5안 3) 유튜브 설명란 초안 (300자 내외) 4) 관련 태그 10개"

Claude는 스크립트 맥락을 공유한 상태로 네 항목을 한 응답에 돌려줍니다.

반례

항목을 따로따로 4번 대화하면 어떻게 될까요?

Claude는 매번 맥락을 새로 해석합니다.

제목과 설명란의 톤이 달라지고, 썸네일 카피와 제목이 충돌하는 경우가 생깁니다.

배치로 한 번에 요청해야 일관성이 유지됩니다.

정리

배치 생성 = 출력 항목을 번호 목록으로 명시 + 스크립트는 프롬프트 맨 앞에 한 번만.

중요 개념 2 — 클릭률 높은 제목의 3가지 패턴

설명

유튜브 제목은 크게 3가지 패턴으로 나뉩니다.

숫자로 기억하세요. 3P: Pain(고통), Promise(약속), Proof(증거).

Pain 패턴: 시청자의 불편을 제목에 넣습니다.

"제목 못 정해서 발행 못 하는 분들께"

Promise 패턴: 결과를 제목에 선언합니다.

"스크립트 넣으면 제목이 5개 나옵니다"

Proof 패턴: 숫자나 기간으로 신뢰를 더합니다.

"6개월 동안 주 1회 발행한 실제 방법"

예시

Claude에게 5안을 요청할 때 이렇게 명시합니다.

"Pain 패턴 2안, Promise 패턴 2안, Proof 패턴 1안으로 각각 만들어 주세요."

패턴을 지정하면 제목 5개가 무작위로 나오는 것이 아니라, 맞춰으로 분산됩니다.

반례

패턴 지정 없이 "제목 5개 만들어줘"라고만 하면 어떻게 될까요?

대부분의 경우 Promise 패턴으로 비슷한 문장이 몰립니다.

선택지가 넓어 보여도 실제로는 하나의 접근이 반복되는 상황입니다.

정리

제목 5안 = Pain 2 / Promise 2 / Proof 1. 패턴을 프롬프트에 직접 지시합니다.

중요 개념 3 — SEO 설명란의 4가지 구성 요소

설명

유튜브 설명란은 검색 노출과 클릭 후 이탈 방지를 동시에 담당합니다.

메모리 페그는 "HKLT" — Hook, Keyword, Link, Tag.

Hook (첫 2줄): 유튜브는 설명란을 2줄만 미리 보여줍니다.

첫 2줄 안에 중요한 문장이 들어가야 합니다.

Keyword (본문): 영상에서 다루는 중요한 단어를 자연스럽게 녹입니다.

키워드 나열이 아니라 문장 안에 배치합니다.

Link (중간): 관련 영상, 이전 차시, 무료 자료 링크를 배치합니다.

Tag (하단): 해시태그 3~5개를 설명란 맨 아래에 둡니다.

유튜브 공식 권고 기준입니다.

예시

Claude에게 이렇게 요청합니다.

"설명란은 HKLT 구조로 작성해 주세요. Hook: 첫 2줄에 중요한 요약. Keyword: 본문에 자연스럽게 삽입. Link: [링크 삽입 위치] 표시로 비워두기. Tag: 하단에 해시태그 5개."

Link 위치는 Claude가 채울 수 없으니, 플레이스홀더로 받는 것이 빠른입니다.

반례

설명란을 단순히 "영상 요약해줘"로 요청하면 어떻게 될까요?

키워드 밀도가 낮고, 첫 2줄이 인트로 인사로 시작되는 경우가 많습니다.

검색 노출에서 불리하고, 시청자가 설명란을 더 펼쳐 볼 이유도 없어집니다.

정리

SEO 설명란 = HKLT 구조를 프롬프트에 명시. Link는 플레이스홀더로 받습니다.

EXERCISE (3–4분)

지금 영상을 일시정지하세요.

오늘 실습의 최종 결과물은 발행 메타데이터 패키지 문서 1개입니다.

Step 1 — 스크립트 준비 (1분)

4차시에서 완성한 스크립트를 엽니다.

없다면, 최근에 완성한 영상 스크립트 아무거나 사용합니다.

Step 2 — 배치 프롬프트 작성 (2분)

아래 틀을 복사해서 Claude에 붙여넣습니다.

[스크립트 전문을 여기에 붙여넣으세요]

위 스크립트를 기반으로 아래 항목을 각각 생성해 주세요.

1) 썸네일 카피 3안 — 각 15자 이내, 강렬한 동사 포함 2) 유튜브 제목 5안 — Pain 2안, Promise 2안, Proof 1안 패턴으로 3) 유튜브 설명란 초안 — HKLT 구조, Link 위치는 [링크]로 표시 4) 관련 태그 10개 — 쉼표로 구분

Step 3 — 채택 및 수정 (1분)

Claude 결과물을 받으면 각 항목에서 1개씩만 고릅니다.

고른 이유를 한 줄씩 옆에 메모합니다.

선택한 제목은 30자를 넘으면 줄입니다.

설명란 첫 2줄은 직접 읽어보고, 중요한이 빠졌으면 수정합니다.

Step 4 — 문서 저장

노션, 구글 독스, 어디든 좋습니다.

파일명은 "YYYYMMDD_채널명_메타데이터" 형식으로 저장합니다.

이 문서가 오늘의 발행 메타데이터 패키지입니다.

CTA (30초)

다음 차시는 드디어 실제 발행 단계입니다.

메타데이터 패키지를 들고 유튜브 스튜디오에 들어가서, 예약 발행까지 세팅하는 전체 흐름을 다룹니다.

오늘 만든 문서, 다음 영상에서 바로 씁니다.

지금 바로 다음 영상으로 넘어가세요.

예상 분량: 15분
