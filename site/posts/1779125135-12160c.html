#9 애드센스·네이버 광고 신청lecture_script

코스: test-1tier-upgrade-1779124486 · 에이전트: producer

HOOK (45초)

오늘 아침에도 블로그 글 올렸죠?

포스팅 30개 넘었고, 방문자도 조금씩 늘고 있는데.

막상 애드센스 신청 버튼 앞에서 멈췄을 거예요.

"조건이 뭐지? 거절당하면 어떡하지?"

그 화면 닫고 유튜브로 넘어간 경험, 저도 있습니다.

이번 차시에서 신청 전 체크할 것 5가지를 짚고, 실제로 제출까지 끝냅니다.

PROMISE (30초)

이 영상이 끝나면, 구글 애드센스 또는 네이버 인플루언서 신청서를 직접 제출하고 캡처 화면 1장을 손에 쥘 수 있습니다.

CORE (8–10분)

개념 1. 애드센스 승인 조건 체크 5가지

설명

구글은 신청 페이지에 조건을 친절하게 안 써줍니다.

제 경험상 아래 5가지가 실제 승인·거절을 가릅니다.

메모리 페그 — "포·도·나·주·연"

포스팅 수, 도메인 연결, 나만의 글, 주제 일관성, 연락처 페이지

① 포스팅 수 — 최소 20~30개, 글자 수 800자 이상짜리.

② 도메인 연결 — 무료 blogspot·tistory 서브도메인은 가능하지만, 개인 도메인 연결 블로그가 심사 통과율이 눈에 띄게 높습니다.

③ 나만의 글 — 타 사이트 복붙, AI 원문 그대로 붙여넣기는 거절 사유 1위입니다. AI로 초안 쓰더라도 내 말투로 30% 이상 고쳐야 합니다.

④ 주제 일관성 — 맛집 1개, 재테크 1개, 육아 1개 이렇게 섞인 블로그는 구글이 카테고리를 못 잡습니다. 주제를 2개 이내로 묶으세요.

⑤ 연락처 페이지 — '소개(About)' 또는 '문의' 페이지 1개. 없으면 거절됩니다.

예시

티스토리에서 '퇴근 후 부업' 단일 주제로 28개 포스팅, 개인 도메인 연결, About 페이지 있음 → 신청 14일 만에 승인.

반례

네이버 블로그에서 티스토리로 글 복사 이전 후 바로 신청 → 즉시 거절.

정리

체크리스트 5개 중 하나라도 빠지면 심사 전에 걸립니다. 제출 전에 5개 전부 확인하세요.

개념 2. 네이버 인플루언서 지수 기준

설명

네이버 인플루언서는 구글 애드센스보다 기준이 조금 다릅니다.

메모리 페그 — "3·30·3"

블로그 운영 3개월 이상, 최근 3개월 포스팅 30개 이상, 이웃 수 3,000명 이상

① 운영 기간 — 개설일 기준 3개월.

② 포스팅 수 — 최근 90일 안에 30개. 즉 3일에 1개 꼴.

③ 이웃 수 — 공식 수치는 없지만, 제 경험상 이웃 3,000명 미만이면 심사 통과가 드뭅니다. 서로이웃 맞교환 커뮤니티(네이버 카페)를 쓰면 2~3주 안에 채울 수 있습니다.

추가로 '주제 카테고리' 선택이 있는데, 세분화된 카테고리(예: 살림·정리 → 살림)를 고를수록 경쟁자가 줄어 통과율이 올라갑니다.

예시

개설 4개월차, 이웃 3,200명, 최근 90일 포스팅 33개 → '살림' 카테고리 신청 후 21일 내 승인.

반례

개설 2개월차에 이웃 5,000명이어도 기간 미달로 자동 거절.

정리

기간·포스팅 수·이웃 수 세 가지 숫자 먼저 채우고 신청 버튼을 누르세요. 순서가 바뀌면 시간만 버립니다.

개념 3. 거절 사유 Top 3와 대응법

설명

메모리 페그 — "복·부·뼈대"

복사 콘텐츠, 부족한 콘텐츠 양, 뼈대(구조) 없는 사이트

① 복사 콘텐츠 (가장 많음)

구글은 카피킬러보다 정확합니다.

원문 대비 50% 이상 같으면 복사로 판정합니다.

대응: AI 초안 → 내 경험 문장 2~3개 추가 → 소제목 구조 바꾸기. 이 세 단계면 통과 확률이 올라갑니다.

② 부족한 콘텐츠 양

거절 메일에 "콘텐츠가 충분하지 않다"고 나올 때입니다.

포스팅 수보다 글 1개당 깊이가 문제인 경우가 많습니다.

대응: 800자짜리 글 5개를 지우고, 1,500자 이상짜리 글 3개로 바꾸세요.

③ 뼈대 없는 사이트

About 페이지, 개인정보처리방침, 카테고리 메뉴 중 하나라도 없으면 거절됩니다.

대응: 티스토리 기준 '페이지' 메뉴에서 각각 1개씩 만들면 30분 안에 해결됩니다.

예시

거절 2회 후 About 페이지 + 개인정보처리방침 추가, 짧은 글 8개 삭제 → 3차 신청에서 승인.

반례

거절 메일 무시하고 재신청만 반복 → 계정 90일 심사 잠금.

정리

거절 메일을 받으면 버리지 말고 열어보세요. 사유가 적혀 있습니다. 그 문장 하나가 재신청 전략을 바꿔줍니다.

EXERCISE (3–4분)

영상 지금 일시정지하세요.

아래 순서대로 따라오면 됩니다.

[산출물 A] 신청 완료 캡처 화면 1장

  1. 아래 체크리스트를 먼저 확인하세요. (다음 단계에서 설명)
  2. 구글 애드센스 신청자: adsense.google.com → '지금 시작하기' → 블로그 URL 입력 → 제출.
  3. 네이버 인플루언서 신청자: 네이버 앱 → 내 채널 → 인플루언서 신청 탭 → 카테고리 선택 → 제출.
  4. 제출 완료 화면 바로 캡처. 파일명: 애드센스_신청완료_날짜.png

[산출물 B] 보완 체크리스트 작성

아래 표를 종이나 노션에 그대로 옮겨 적고, 체크 안 된 항목은 날짜 옆에 '보완 예정일'을 씁니다.

항목 완료 여부 보완 예정일
포스팅 20개 이상 (800자↑) ☐
개인 도메인 연결 또는 서브도메인 확인 ☐
About·소개 페이지 ☐
개인정보처리방침 페이지 ☐
복사 글 없음 확인 ☐
(네이버 전용) 이웃 3,000명 이상 ☐
(네이버 전용) 운영 3개월 이상 ☐

체크리스트 5개 이상 완료됐다면 바로 제출해도 됩니다.

아직 2~3개가 비어있다면, 보완 예정일 먼저 쓰고 다음 차시로 넘어가세요.

CTA (30초)

다음 차시는 '첫 광고 수익 캡처하기'입니다.

신청 후 심사 중에 준비해두면 승인 당일 바로 쓸 수 있는 내용입니다.

오늘 신청 완료 캡처 화면, 댓글에 올려주세요.

"완료"한 글자만 달아도 됩니다. 서로 확인하면 포기율이 반 이상 줄어듭니다.
