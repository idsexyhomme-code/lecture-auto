#7 SNS·뉴스레터 콘텐츠 배치 생성하기lecture_script

코스: claude-autowork · 에이전트: producer

HOOK (45초)

콘텐츠 하나 올리려고 인스타 따로, 링크드인 따로, 뉴스레터 따로 쓰다가 하루가 다 가신 적 있으신가요?

같은 내용인데 채널마다 말투가 달라야 하고, 분량이 달라야 하고, 해시태그도 다 따로 챙겨야 하죠.

오늘 이 영상이 끝나면 그 작업을 Claude 한 번으로 끝내실 수 있습니다.

아이디어 하나 → 3채널 초안 동시 완성, 지금 바로 시작합니다.

PROMISE (30초)

이번 차시가 끝나면 중요한 아이디어 하나를 입력해서 인스타그램·링크드인·뉴스레터용 콘텐츠 초안을 Claude로 한 번에 뽑아내는 배치 프롬프트를 직접 설계하고 실행할 수 있게 됩니다.

CORE (8–10분)

중요 개념 1 — 채널별 어조 차별화

설명

채널마다 독자가 기대하는 말투가 다릅니다.

인스타는 짧고 감성적인 '친구 말투'입니다. 링크드인은 신뢰감 있는 '동료 전문가 말투'입니다. 뉴스레터는 깊이 있는 '편지 말투'입니다.

이 세 가지를 섞으면 어디서도 어색해집니다.

예시

'생산성을 높이는 아침 루틴'이라는 아이디어가 있다고 해봅시다.

인스타: "오전 7시, 딱 20분이 하루를 바꿉니다 ✨ #아침루틴" 링크드인: "생산성 연구 34편을 분석한 결과, 아침 루틴의 중요한은 '의사결정 순서'였습니다." 뉴스레터: "안녕하세요. 오늘은 제가 6개월간 직접 실험한 아침 루틴 이야기를 나눕니다."

반례

링크드인에 인스타 말투를 쓰면 어떻게 될까요? "오늘 아침도 루틴 완료 🔥 회원님은요?" — 전문성이 증발합니다.

반대로 인스타에 뉴스레터 말투를 쓰면 아무도 끝까지 읽지 않습니다.

정리 — 메모리 페그 '3색 마이크'

인스타(핑크·감성), 링크드인(네이비·전문성), 뉴스레터(크림·깊이). Claude에게 각 채널을 이 색깔로 설명해 주면 어조 차별화가 훨씬 쉬워집니다.

중요 개념 2 — 원소스 멀티유즈 방법

설명

원소스 멀티유즈란 하나의 중요한 메시지에서 여러 콘텐츠를 파생시키는 방법입니다.

중요한은 '원본'을 먼저 탄탄하게 정의하는 것입니다. 원본이 흔들리면 파생 결과물도 모두 흔들립니다.

원본을 구성하는 세 요소는 이렇습니다. ① 중요한 주장 한 문장 ② 근거 또는 사례 2–3개 ③ 독자에게 주는 행동 제안 1개

예시

중요한 주장: "짧은 회의가 더 많은 것을 결정합니다." 근거: 15분 회의 실험 데이터, 본인 사례 행동 제안: 다음 회의 시간을 반으로 줄여보세요.

이 세 요소를 Claude에게 주면, Claude가 채널별 형식으로 재구성합니다.

반례

원본 없이 "SNS 콘텐츠 써줘"라고만 하면 어떻게 될까요? Claude가 방향을 스스로 정하게 됩니다. 결과물이 나오긴 하지만 일관된 메시지가 없습니다.

수정 횟수가 3배 이상 늘어나는 경우가 대부분입니다.

정리 — 메모리 페그 '나무 한 그루'

원본은 뿌리입니다. 인스타·링크드인·뉴스레터는 가지입니다. 뿌리가 깊어야 가지가 튼튼합니다. Claude는 좋은 정원사지만, 씨앗은 회원님이 심어야 합니다.

중요 개념 3 — 배치 프롬프트 설계

설명

배치 프롬프트란 여러 작업 지시를 하나의 프롬프트에 담는 설계 방식입니다.

중요한 구조는 네 칸입니다. ① 역할 설정 — Claude에게 어떤 전문가로 행동할지 부여 ② 원본 소스 — 중요한 주장·근거·행동 제안 입력 ③ 채널별 스펙 — 각 채널의 형식과 분량, 어조 지정 ④ 출력 형식 — 채널별로 구분해서 출력하도록 요청

예시

실제 프롬프트 구조를 보여드리겠습니다.

"당신은 B2B 콘텐츠 마케터입니다. 아래 중요한 아이디어를 바탕으로 세 가지 채널용 초안을 작성해 주세요.

[중요한 아이디어] 주장: 짧은 회의가 더 많은 것을 결정합니다. 근거: 15분 회의 그룹이 60분 회의 그룹보다 실행률이 40% 높았습니다. 행동 제안: 다음 회의를 15분으로 설정해 보세요.

[채널 스펙] 인스타그램: 150자 이내, 감성적 어조, 이모지 2–3개, 해시태그 5개 링크드인: 300자 내외, 전문가 어조, 데이터 강조, 해시태그 3개 뉴스레터: 400–500자, 편지 형식, 소제목 1개 포함

[출력 형식] 각 채널을 구분선으로 분리해서 보여주세요."

반례

채널 스펙을 빠뜨리면 어떻게 될까요? Claude가 인스타와 링크드인을 비슷한 분량으로 씁니다. 또는 해시태그를 모든 채널에 동일하게 붙이기도 합니다. 스펙이 정확할수록 수정 횟수가 줄어듭니다.

정리 — 메모리 페그 '4칸 서랍장'

역할·소스·스펙·형식, 이 네 칸을 채우는 것이 배치 프롬프트의 전부입니다. 한 칸이라도 비면 결과물이 흔들립니다.

EXERCISE (3–4분)

지금 영상을 일시정지하고 직접 해보실 차례입니다.

아래 4단계를 순서대로 따라해 주세요.

Step 1 — 중요한 아이디어 정의하기 (1분)

지금 회원님이 다루고 싶은 주제를 하나 고르세요. 아래 세 줄을 직접 채워주세요.

  • 중요한 주장: (한 문장으로)
  • 근거 또는 사례: (2개)
  • 행동 제안: (한 문장으로)

Step 2 — 채널 스펙 메모하기 (30초)

인스타그램, 링크드인, 뉴스레터 각각의 목표 분량과 어조를 한 줄씩 적어두세요. 오늘 배운 '3색 마이크'를 떠올리며 작성해 보세요.

Step 3 — 4칸 서랍장 채워 프롬프트 완성하기 (1분)

역할·소스·스펙·형식, 네 칸을 채워서 프롬프트 초안을 완성하세요. 앞서 본 예시를 참고 템플릿으로 사용하셔도 됩니다.

Step 4 — Claude에 입력 후 결과 확인 (1분)

완성한 프롬프트를 Claude에 붙여넣고 실행하세요. 결과물에서 이 세 가지를 확인해 보세요.

  • 채널별 어조가 실제로 다른가?
  • 분량이 스펙에 맞는가?
  • 중요한 주장이 세 채널 모두에 살아있는가?

한 가지라도 아니라면, 해당 스펙만 수정해서 다시 실행해 보세요.

CTA (30초)

오늘 만드신 프롬프트와 결과물, 댓글에 공유해 주시면 제가 직접 피드백 드리겠습니다.

다음 차시 #8에서는 오늘 생성한 콘텐츠를 노션 데이터베이스에 자동 정리하는 방법를 다룹니다.

Claude가 쓰고, 노션이 정리하는 흐름, 기대해 주세요.

예상 분량: 15분
