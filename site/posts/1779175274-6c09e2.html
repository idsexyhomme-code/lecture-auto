#6 클릭 당기는 썸네일 만든다lecture_script

코스: test-1tier-upgrade-1779174833 · 에이전트: producer

HOOK (45초)

어제 올린 영상, 조회수 12예요.

썸네일 때문입니다. 솔직히.

피드에서 0.3초 안에 안 잡히면 그냥 지나칩니다.

텍스트가 너무 많거나, 얼굴이 없거나, 배경이 칙칙하거나.

셋 중 하나만 틀려도 그냥 스크롤됩니다.

오늘 이 영상 하나로 그 문제 끝냅니다.

PROMISE (30초)

이 차시가 끝나면, Canva에서 텍스트 7자·얼굴 사진·배경 대비까지 세 가지가 다 들어간 썸네일 1장을 직접 완성합니다.

CORE (8–10분)

개념 1 — 썸네일 텍스트 7자 법칙

설명

모바일 피드 기준, 썸네일 크기는 손가락 두 마디 정도입니다.

그 안에 글자가 10자 넘어가면 읽히지 않습니다. 눈이 그냥 넘깁니다.

7자가 한계선입니다.

예시

"유튜브 알고리즘 완전 정복 방법" → 탈락.

"알고리즘 끝" → 통과.

"월 500 버는 법" → 6자. 딱 맞습니다.

반례

"메일 잘 쓰는 7가지 방법" — 이건 7자처럼 보이지만 썸네일에 올리면 글씨가 작아져서 뭉개집니다.

숫자+명사+동사, 이 세 단어 조합이 제일 잘 읽힙니다.

정리 — 메모리 페그: "7자 칼"

칼처럼 7자로 딱 자릅니다. 글자 수 세고, 넘으면 잘라냅니다. 끝.

개념 2 — 얼굴 클로즈업 효과

설명

사람 뇌는 얼굴을 먼저 봅니다.

피드에서 얼굴이 없는 썸네일보다 얼굴이 있는 썸네일, 클릭률이 제 채널 기준 평균 1.8배 차이 났습니다.

단, 얼굴 전체가 아니라 눈·코·입이 다 보이는 클로즈업이어야 합니다.

멀리서 찍은 전신 사진은 피드에서 점으로 보입니다.

예시

스마트폰으로 어깨 위만 잘라 찍은 사진. 표정은 살짝 놀란 듯 또는 단호한 표정. 이 두 가지가 피드에서 시선을 가장 잘 잡습니다.

반례

웃는 증명사진 스타일 — 신뢰는 가지만 클릭 욕구를 못 만듭니다.

썸네일에서 웃음은 '친근함'이지 '궁금함'이 아닙니다.

정리 — 메모리 페그: "얼굴 = 낚싯바늘"

낚싯바늘 없이 낚시하면 물고기가 안 옵니다. 얼굴 없는 썸네일도 마찬가지입니다.

개념 3 — 배경색 대비 원칙

설명

Canva 기본 흰 배경에 흰 옷 입고 찍으면 사람이 배경에 녹아 없어집니다.

대비란 간단합니다. 밝은 배경에는 어두운 텍스트, 어두운 배경에는 밝은 텍스트.

배경색과 텍스트 색, 두 색의 밝기 차이가 클수록 읽힙니다.

제 경험상 노란 배경에 검정 텍스트, 남색 배경에 흰 텍스트, 이 두 조합이 어떤 기기에서도 잘 보입니다.

예시

노란 배경(#FFC800) + 검정 텍스트(#000000) + 얼굴 사진 오른쪽 배치.

이게 유튜브 교육 카테고리에서 대부분의 경우 클릭률이 높게 나오는 조합입니다.

반례

빨강 배경에 주황 텍스트 — 둘 다 비슷한 밝기여서 글씨가 안 보입니다. 강렬해 보이려다 오히려 읽히지 않습니다.

정리 — 메모리 페그: "신호등 3색"

신호등은 색이 다 다릅니다. 배경·텍스트·얼굴, 이 세 요소도 색이 겹치면 안 됩니다. 신호등처럼 각자 명확하게 구분합니다.

EXERCISE (3–4분)

지금 영상 잠깐 멈추세요.

Canva 열고 따라 하면 됩니다.

Step 1 — 캔버스 만들기

Canva 접속 → '새 디자인' 클릭 → 'YouTube 썸네일' 검색 → 1280×720px 캔버스 선택합니다.

Step 2 — 배경색 설정

왼쪽 '배경색' 클릭 → 색상 코드 입력창에 FFC800 입력 → 노란 배경 완성.

어두운 계열 배경을 쓰고 싶으면 1A237E(남색) 입력해도 됩니다.

Step 3 — 얼굴 사진 넣기

'업로드' 탭 → 스마트폰으로 찍은 얼굴 클로즈업 사진 올리기 → 캔버스 오른쪽에 배치 → 어깨 아래는 잘라냅니다.

사진이 없으면 지금 스마트폰으로 셀카 한 장 찍고 올리면 됩니다. 30초면 됩니다.

Step 4 — 텍스트 7자 넣기

'텍스트' → '제목 추가' → 오늘 만들 영상 주제를 7자 이내로 입력.

예: "메일 3분 끝", "견적 1분 완성"

텍스트 색상은 검정(000000) 또는 흰색(FFFFFF) — 배경색 반대로 고릅니다.

텍스트는 캔버스 왼쪽 절반에 크게 배치합니다.

Step 5 — 저장

오른쪽 위 '공유' → '다운로드' → PNG 선택 → 저장.

썸네일 1장 완성입니다.

CTA (30초)

다음 차시에서는 이 썸네일에 맞는 제목 짜는 법을 다룹니다.

클릭을 당기는 썸네일 만들었으면, 제목이 그 클릭을 끝까지 붙잡아야 합니다.

오늘 만든 썸네일 사진, 댓글에 올려보세요. 직접 피드백 남깁니다.

예상 분량: 15분
