## 💰 결제 흐름 (스마트스토어 외부 결제)

```
[사용자 여정]

1. 랜딩 페이지 (index.html)
   ↓ "네이버페이로 결제하기" 클릭
2. 네이버 스마트스토어 상품 페이지 (외부 이동)
   ↓ 9,900원 결제
3. 회원이 결제 알림 받음 (스마트스토어 판매자센터)
   ↓
4. 회원이 구매자에게 정보 입력 폼 발송 (수동 또는 자동)
   ↓
5. 구매자가 폼 작성 (이름·성별·생년월일·태어난 시간·이메일)
   ↓
6. 회원이 결과 생성 (multi_llm.py + result-template.html 변수 치환)
   ↓
7. results/{token}.html 파일 생성
   ↓
8. 구매자에게 결과 URL 이메일 발송
   ↓
9. 구매자 결과 페이지 영구 보관 (북마크해서 다시 방문 가능)
```

## ⚙️ 초기 셋업 (출시 전 1회만)

### 1. 네이버 스마트스토어 상품 등록
- 상품명: **숲사주 — AI 사주 웹 리포트**
- 가격: **9,900원**
- 카테고리: 디지털 콘텐츠 → 운세
- 배송 정보: 디지털 자동 발송 (없음)
- 환불 정책: "결과 발송 전 전액 환불 가능"
- 상품 상세 페이지에 안내문:
  > 결제 후 별도 안내드리는 정보 입력 폼에
  > 이름·성별·생년월일·태어난 시간을 입력해주세요.
  > 24시간 안에 구매자 전용 결과 페이지를 이메일로 보내드립니다.

### 2. 상품 URL 등록 (HTML 1줄 수정)

`index.html` 파일 마지막의 `<script>` 안:

```javascript
const SMARTSTORE_URL = "https://smartstore.naver.com/YOUR_STORE_NAME/products/YOUR_PRODUCT_ID";
```

→ 본인 스마트스토어 상품 URL로 교체

### 3. 정보 입력 폼 만들기 (Google Forms 권장)

**필드 구성**:
- 이름 (단답)
- 성별 (라디오: 남성·여성·기타)
- 생년월일 (날짜)
- 태어난 시간 (단답: "오전 9시 22분" 또는 "모름")
- 받을 이메일 (이메일)
- 결제 영수증 번호 (단답) — 스마트스토어 확인용

→ 폼 URL을 스마트스토어 결제 완료 안내 메시지에 포함

### 4. 이메일 발송 템플릿 준비

회원이 결과 생성 후 구매자에게 보낼 이메일 (Gmail 템플릿):

```
제목: 🌿 [숲사주] {{NAME}}님의 결과 페이지가 준비됐어요

{{NAME}}님 안녕하세요.
숲사주 리포트 준비됐어요. 아래 링크에서 확인해주세요 🌳

▶ 내 결과 페이지:
https://yourdomain.com/forest-saju/results/{{TOKEN}}.html

* 영구 보관됩니다. 북마크해두고 두고두고 보세요.
* 다른 분 결과는 별도 결제가 필요해요.

문의: hello@forest-saju.app
```

## 🎯 결과 생성 방법 (3가지 옵션)

### 옵션 A — 수동 (출시 초기, 일 1~10건)

1. 폼에서 정보 받음
2. `result-template.html` 복사 → `results/{token}.html` 저장
3. 텍스트 에디터로 `{{변수}}` 14개 치환
4. 토큰 URL 이메일 발송

→ **건당 10~15분 작업**. 출시 초기에 적합.

### 옵션 B — 반자동 (Python 스크립트, 일 10~50건)

`scripts/generate_forest_saju.py` (별도 작성 필요):
- Google Forms 응답을 Sheet 또는 CSV로 export
- multi_llm.py 호출해서 8개 카드 본문 생성
- Jinja2로 template 치환
- 결과 파일 자동 저장 + 이메일 자동 발송

→ **건당 1~2분 자동화**. 50건/일 이상 처리 가능.

### 옵션 C — 완전 자동 (Webhook, 일 100건+)

- Naver Pay Webhook → Cloudflare Worker → 자동 폼 발송
- 폼 제출 시 → multi_llm 자동 호출 → 결과 자동 생성 → 자동 이메일

→ **0초 작업**. 매출 검증 후 구현.

## 🤖 8개 카드 system prompt 가이드

각 카드는 3 AI 관점(Claude + ChatGPT + Gemini)이 분석한 결과를 통합합니다.

### 카드별 핵심 분석 영역

| 카드 | 영역 | 핵심 질문 |
|---|---|---|
| 01 기본 성향 | 사람의 기본 결·일하는 방식 | "이 사람의 본질은?" |
| 02 연애운 | 연애 흐름·패턴·다가올 인연 | "다음 3개월의 설렘 흐름은?" |
| 03 결혼·동반자 | 결혼 적기·맞는 동반자 | "함께 자랄 사람의 결은?" |
| 04 재물운 | 돈 다루는 성향·재물 흐름 | "이 사람의 재물 패턴은?" |
| 05 일·사업운 | 직업·창업 방향·일의 결 | "어떤 일에 빛이 나는가?" |
| 06 인간관계운 | 가족·친구·동료 관계 패턴 | "관계의 결과 갈등 영역은?" |
| 07 조심할 흐름 | 피해야 할 결정·반복 실수 | "이 사람이 조심할 부분은?" |
| 08 이번 달 조언 | 한 줄 가이드 (월별 갱신) | "이번 달 가장 중요한 한 문장은?" |

### 공통 작성 원칙 (헌법 §4 정합)

- "운명", "100%", "보장", "확실히" 금지
- "참고용", "흐름", "패턴", "결" 권장
- 따뜻하고 부드러운 어조 (다정한 친구 톤)
- 한 카드 본문 = 2단락 + 1줄 highlight
- 한자·전문 용어 X, 쉬운 한국어
- 일러스트 가능한 메타포 활용 (숲·나무·새싹·잎)
