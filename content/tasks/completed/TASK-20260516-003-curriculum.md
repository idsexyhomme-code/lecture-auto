# TASK-20260516-003 — curriculum_agent

---

## 코스 개요

**제목:** 1인 사업가를 위한 AI 업무 자동화

**가치제안:**
매일 반복하는 업무를 ChatGPT·Make·Notion으로 직접 연결한다. 강의 6개, 각 15분. 끝나면 내 업무 흐름 하나가 실제로 돌아간다.

**이 코스가 약속하는 것 3가지:**
1. 반복 업무 하나를 골라 직접 자동으로 돌린다
2. 도구 연결 방법을 손으로 익힌다
3. 강의가 끝날 때마다 내 컴퓨터에 결과가 남는다

---

## 6강 커리큘럼 초안

---

### 1강 — 내 시간을 가장 많이 먹는 업무 1개 찾기

**분량:** 13분

**학습목표:**
수강 후, 내 일주일 업무 목록에서 "매주 같은 방식으로 반복되는 작업 1개"를 골라 이름과 소요 시간을 적을 수 있다.

**중요 개념 3가지:**
- 반복 작업 vs 판단 작업 — 자동으로 넘길 수 있는 것과 없는 것을 나누는 기준
- 시간 기록 — 하루 30분 이상 쓰는 작업이 첫 번째 후보
- 80/20 — 전체 업무 중 20%가 시간의 80%를 잡아먹는다

**실습:**
지난 한 주 업무를 5개 이상 적고, 각 항목에 소요 시간·반복 주기를 붙인다. 그 중 반복 빈도×시간이 가장 큰 1개에 동그라미.

**실습 결과물:**
내 업무 목록 메모 (Notion 페이지 또는 A4 1장) — 반복 작업 1개 확정

**도구:** Notion (또는 종이)

---

### 2강 — ChatGPT에게 내 업무를 맡기는 방법

**분량:** 15분

**학습목표:**
수강 후, 1강에서 고른 반복 업무 1개에 대해 ChatGPT가 매번 같은 품질로 결과를 내는 프롬프트를 직접 작성할 수 있다.

**중요 개념 3가지:**
- 역할 부여 — "넌 내 업무 담당자야"라고 먼저 알려주는 이유
- 조건 명시 — 길이·형식·말투를 구체적으로 적어야 매번 같은 결과가 나온다
- 반복 사용 프롬프트 — 템플릿으로 저장해 두는 법

**실습:**
1강 결과물(반복 작업 1개)을 ChatGPT에게 시키는 프롬프트를 3번 고쳐 쓴다. 마지막 버전을 Notion에 저장.

**실습 결과물:**
나만의 프롬프트 1개 — Notion에 저장된 텍스트 블록

**도구:** ChatGPT (무료 또는 Plus), Notion

---

### 3강 — Make로 두 개 앱을 연결하는 첫 번째 시나리오

**분량:** 15분

**학습목표:**
수강 후, Make에서 트리거 1개·액션 1개짜리 시나리오를 혼자 만들어 테스트 실행을 통과시킬 수 있다.

**중요 개념 3가지:**
- 트리거 — "이 일이 생기면"에 해당하는 시작 조건
- 액션 — "이걸 해라"에 해당하는 실행 명령
- 에러 로그 — 연결이 끊겼을 때 어디서 멈췄는지 읽는 법

**실습:**
Gmail 받은편지함에 새 메일 도착 → Notion 특정 페이지에 제목·발신자·날짜 자동 기록. Make에서 직접 만들고 테스트 실행 1회 성공.

**실습 결과물:**
Make 시나리오 1개 (스크린샷 저장) + Notion에 자동 기록된 메일 데이터 1건

**도구:** Make (무료 플랜), Gmail, Notion

---

### 4강 — ChatGPT와 Make를 한 줄로 잇기

**분량:** 15분

**학습목표:**
수강 후, Make 시나리오 안에서 ChatGPT API를 호출해 텍스트를 받아 Notion에 저장하는 흐름을 혼자 완성할 수 있다.

**중요 개념 3가지:**
- API 키 — 발급·입력·보관하는 법 (유출되면 비용 청구됨)
- HTTP 모듈 — Make에서 ChatGPT를 부르는 가장 간단한 방법
- 토큰 비용 — GPT-4o mini 기준 1회 호출에 얼마나 드는지

**실습:**
3강 시나리오에 ChatGPT 호출 1개 추가 — 받은 메일 제목을 넣으면 ChatGPT가 한 줄 요약을 돌려주고, 그 요약이 Notion에 함께 기록됨.

**실습 결과물:**
Make 시나리오 업데이트본 (스크린샷) + Notion에 메일 제목·ChatGPT 요약이 함께 저장된 행 1개

**도구:** Make, ChatGPT API (OpenAI 계정), Notion

---

### 5강 — 고객 응대·보고서·견적 — 내 업무에 맞게 바꾸기

**분량:** 14분

**학습목표:**
수강 후, 1강에서 고른 내 반복 업무에 4강 흐름을 직접 적용한 시나리오 1개를 혼자 만들 수 있다.

**중요 개념 3가지:**
- 입력 데이터 매핑 — 어떤 앱의 어떤 필드를 ChatGPT에 넣을지 미리 그리는 법
- 분기 처리 — 조건에 따라 다른 액션으로 나눌 때 (예: 메일 발신자가 VIP면 다른 알림)
- 모듈 복사·재사용 — 만든 시나리오를 다른 업무에 붙여 쓰는 법

**실습:**
내 반복 업무 1개(고객 응대 메일 초안 / 주간 보고서 정리 / 견적 문서 요약 중 택1)에 Make + ChatGPT를 연결한 시나리오 직접 완성. 테스트 실행 1회 성공.

**실습 결과물:**
내 업무 전용 Make 시나리오 1개 (스크린샷) + 실제 결과가 저장된 Notion 페이지

**도구:** Make, ChatGPT API, Notion (또는 Google Sheets)

### 6강 — 혼자 돌아가게 두기 전 마지막 점검

**분량:** 13분

**학습목표:**
수강 후, 5강까지 만든 시나리오를 스케줄 실행으로 전환하고, 에러가 났을 때 이메일 알림을 받는 설정까지 혼자 완료할 수 있다.

**중요 개념 3가지:**
- 스케줄 트리거 — 매일 오전 9시처럼 시간 기준으로 자동 실행하는 법
- 에러 핸들러 — 시나리오가 멈췄을 때 나한테 알림이 오게 하는 설정
- 실행 이력 확인 — Make 로그에서 성공·실패 건수를 읽는 법

**실습:**
5강 시나리오를 스케줄 실행으로 전환 (매일 또는 매주). 에러 발생 시 내 이메일로 알림 오게 설정. Make 로그에서 테스트 실행 이력 1건 캡처.

**실습 결과물:**
스케줄 실행 중인 Make 시나리오 1개 (스크린샷) + 에러 알림 설정 완료 화면 캡처

**도구:** Make, Gmail (알림 수신용)
